# CHANGELOG — alakazam741_v10_route_eta

## 10.0.0 (2026-07-15)

alakazam741_v9_top8_core をベースに、デッキ構成（v8/v9と完全同一の60枚）と機能している中核（攻撃テンポ・ノココッチ運用・退避制御・状態機械・攻撃予約・動的山札管理）を維持したまま、初動事故・後続の誤判定・非ミラーでの無駄な妨害を狙って7点を修正した論理版。対面別のカード名/デッキ名分岐は追加していない。

### 修正（v9から）

1. **`_holds_complete_route`**: 「ケーシィ＋ユンゲラーを持つだけ」で完成扱いしていた誤判定を廃止。到達可能なフーディン（ケーシィ＋ユンゲラー/ふしぎなアメ＋フーディンのカード＋超エネルギー＋現在の進化可能条件）が揃う場合のみ完成ルートと判定。不完全な手札ではリーリエの手札再構築を止めない。
2. **後続判定を `_backup_eta` へ**: `_has_backup_line`（ベンチにライン札があれば後続あり）を撤廃し、エネルギー込みのETA（0=攻撃可能フーディン、1=フーディン＋今ターン貼れる超エネ/ユンゲラー・アメ経路＋エネ、2=進化ラインありエネなし、3=ケーシィのみ、99=経路なし）へ置換。`backup_eta<=1` のみ十分な後続とみなす。後続エネ不足時（`_backup_energy_short`）はエネルギー確保を優先。
3. **ポケパッドを route deficit 方式に**: 不足している進化段階を取得。場・手札にケーシィがなければケーシィ最優先、ケーシィはあるが経路がなければユンゲラー、アメ経路がありフーディンなしならフーディン。ケーシィ不在でのフーディン先行取得を禁止。
4. **ヒカリ/ヒルダを盤面の不足で使い分け**: 固定点差で常にヒルダを優先しない。ケーシィなし→ヒカリ、ケーシィありエネ/進化札不足→ヒルダ、ケーシィ＋エネありライン不足→ヒカリ、攻撃可能フーディンありで後続エネなし→ヒルダ。
5. **非ミラーのクセロシキを原則禁止**: 相手手札8枚以上だけでは使わない。ミラーかつ攻撃可能な攻撃前妨害としてのみ許可（現在KO/攻撃を失う場合は攻撃前ゲートで却下）。LOCKED中および「攻撃できない状態でクセロシキだけ使ってEND」を禁止。
6. **夜のタンカを1ターン1回に制限**: 同一ターンの2回目以降は、今ターンのKO成立または次の攻撃役確保に直結する場合のみ許可（`_TURN_STATE` によるターン内カウント）。
7. **バトルケージの無条件張り替えを削除**: 相手スタジアムがあるだけでは使わない。実際のベンチ保護が必要な場合のみ。現在KO/攻撃の喪失は攻撃前ゲート（`_preserves_attack`）で別途防止。

### 不変（v9から意図的に維持）

- 60枚デッキ（byte一致）、同梱 `policy_base.py`、Powerful Hand=20×手札の打点モデル。
- PRESSURE状態の攻撃優先、ノココッチ特性の基本Tier・山札管理、攻撃可能なのにENDしない処理、過剰な手動退避の抑制、最後の1体ノココッチ自滅防止、効果無効への0ダメージ攻撃防止。
- ボスの指令なし・対面別分岐なし。
