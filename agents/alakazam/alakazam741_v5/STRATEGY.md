# alakazam741_v5 戦略メモ

## ベース
`alakazam741_v4` + 53戦の実ラダーログ全数分析(sub54576108, 26勝27敗 49.1%)。
分析スクリプト: `experiments/v4_run_analysis/analyze_v4.py` /
レポート: `docs/alakazam741_v5_analysis.md`

## 勝ち筋(不変)
1サイドのフーディン743(Powerful Hand = 20×手札)をノココッチのドローで高火力化し、
1サイド交換を押し付ける。クセロシキでミラーの手札=火力を折り、改造ハンマーで
ミスト系を剥がし、ボスの指令でKO直結のベンチを狩る。

## v4からの変更
### コード (P0)
- **最後の1体ノココッチ特性の絶対禁止**(-100000)。v4実ラダー4敗の直接原因
  (85419845/85420867/85422380/85430151)。引き金だった `_item_locked()` の
  状態誤検知トリガーを廃止し、「ベンチに攻撃可能フーディン」がいる時だけ
  前のRun Away Drawを許可。盤面2体で手札補充なしのベンチ起動も禁止。
- **盤面全体の効果無効の検出**。ロケット団のフリーザー(414)の「たねロケット団
  ポケモン全保護」等を特性テキストスキャンで検出し `_effect_prevented()` を拡張。
  0ダメPowerful Hand連打(85424359で19回→山札切れ)と、0ダメ対象へのボスを排除。
  保護対象外(進化TRポケモン等)は引き続きKO対象として正しく評価される。
- **no-damage-path**(解除見込みのない0ダメ詰み)で任意ドローを停止し山札切れ防止。
  貼りミスト系はハンマーが残っていて山札に余裕がある間は掘り続ける。
- `_deck_preserve` が効果無効の相手を「致死圏」と誤認しないよう修正。

### コード (P1/P2)
- **リーリエの決心ロジック**: 手札全戻し→6枚(自サイドちょうど6なら8枚)。
  致死時・完成コンボ(フーディン+ユンゲラー/アメ)保持時は使わない。
  手札-1 ≤ 目標-3 かつアタッカー不在 → 14200(事故立て直し、ヒルダより優先)。
  手札-1 ≤ 目標-2 → 8600(たね/進化/エネ/ハンマー消化後、ポケパッド8500の直上)。
- **序盤盤面**: T4まで盤面5体未満ならポフィン15200。
  (v4実測: 2回目自ターン終了時に5体以上→勝率86.4%、4体以下→22.6%)
- **ミラー昇格**: 進化フーディンが手札に無い時はユンゲラー(80HP=相手PH一撃圏)
  よりノココッチ壁(140HP)を優先(85449408)。

### デッキ (P1-A)
```text
ポケパッド        3 → 2
リーリエの決心    0 → 1
```
- **ボスの指令2枚維持**: 実ログ23回中21回が次の自ターンまでにサイド獲得、
  23回全てで同ターン攻撃。「ボス0枚」はログと矛盾。
- **クセロシキ3枚維持**: -1枚のA/Bはミラー44.0%(1000戦)に悪化。
- **フーディン245テック見送り**: 同名合計4枚制限で743が3枚になるのが響き
  ミラー37.3%(600戦)。v3のA/B結果を再確認した形。対応コードは温存
  (デッキに1枚入れれば即動く)。
