# alakazam741_v6 戦略メモ

## ベース
`alakazam741_v5` (rev5.1, sub54600504) + ユーザーによるv5ラダー対戦結果の所感。
勝ち筋は不変: 1サイドのフーディン743(Powerful Hand = 20×手札)をノココッチの
ドローで高火力化し、1サイド交換を押し付ける。

## v5からの変更

### ロジック
- **[V6-1] 改造ハンマーの使い所を限定**。相手Activeのミスト/ロック等でPowerful Handが
  0にされていて、1枚剥がせば攻撃が通り「このターン倒しきれる」時のみ使用(16000)。
  プレヴェント特殊エネが「ちょうど1枚」の時に限る(全体保護特性・自身特性・2枚以上は
  1枚のハンマーでは通らないので対象外)。ベンチ含む「特殊エネを見つけ次第剥がす」旧分岐
  (9500)は廃止。例外として、使わないと相手の技で自ActiveがKOされ負ける等の重大局面で、
  剥がせば相手が致死を出せなくなる時のみ阻止に使う(15000)。
- **[V6-2] クセロシキのたくらみの発動条件を追加**(既存トリガーは維持)。
  (a) 形勢不利かつ他に使うべきサポが無い/使わない方が良く、相手手札5枚以上 → 8700。
  (b) クセロシキ未使用 or 手札に2枚 かつ 相手手札6枚以上 → 12000。
- **[V6-3] フーディン攻撃 vs のこっち退避の判断修正**。退避(交換)判定の前に
  「フーディンで攻撃すべきか」を判定する。ベンチに『次フーディンとして昇格すれば
  相手Activeを倒せる後続』がいて、今のActiveがダメージを出せるなら、次ターンにKO
  される見込みでも交換せず攻撃する。攻撃はいつかしないといけず、居座られると
  のこっちを狩られ続けて負けるため、継続手段がある限り殴る(ユーザー例外a/bを内包)。
- **[V6-4] 山札切れ防止の強化**。ミストエネ2枚等「1枚のハンマーでは解除できない」詰みを
  no_damage_path として掘りを停止。詰み中はグッズ/サポによる山札消費を一切停止し、
  毎ターンの強制ドローだけで延命。デッキフロアに相手の残サイド枚数も加味。

### デッキ (V6-5)
```text
のこっち(Dunsparce 305)      4 -> 3
ノココッチ(Dudunsparce 66)   3 -> 2
メガディアンシーex(766)      0 -> 1
リーリエの決心(1227)         1 -> 2
```
- 序盤「のこっち系しか場にいない」事故と、盾/第2アタッカー不足への対策。
- **[V6-6] メガディアンシーex(766)**: たね・HP270・ダイヤコート(被ダメ-30)・
  Garland Ray({P}{P}, 超エネを2枚まで捨てて120×捨てた枚数=最大240)。攻撃は
  「ダメージ」なのでミスト/全体保護を貫通する(対効果無効の第2の回答)。給エネ・攻撃・
  昇格・ベンチ・開始Active選択・サーチ確保に統合。ただしメガex=倒されるとサイド3枚
  のため、それで相手が勝ち切る状況では前に出さない。
  ※ユーザーの「できればex以外で」の希望に対し、指定通り766(メガex)を採用。サイド3枚
  献上リスクは _shield_candidates / _score_active_choice の基準で抑制している。
