# alakazam741_v9_top8_core 戦略概要

上位フーディン8チーム・793試合の再集計から抽出した「汎用コア」を再現する版。デッキはv8と完全に同一の60枚で、変更点はロジックのみ。対面別のカード名・デッキ名分岐は一切追加していない。ボスの指令はデッキに存在せず、専用ロジックも持たない。

## 中心思想

上位の勝ち筋は「即攻撃」でも「安全行動の最大化」でもない。**まず攻撃を予約し、その攻撃を壊さない範囲で進化・ドロー・妨害・後続準備を行い、最後に必ず攻撃する**。この不変条件を、毎回のMAIN選択で一つの状態と一つの攻撃予約として実装する。

## ターン状態機械（毎MAINで一つだけ選ぶ）

- **SETUP**: 攻撃可能なフーディンがいない初期状態。今ターン攻撃できるフーディン完成 → 超エネルギー確保 → 次のケーシィ/ユンゲラー → ノコッチ1体 → 追加展開。盤面5体は目標にせず、役割の充足で判定する。
- **PRESSURE**: 攻撃可能なフーディンがいる状態。最善攻撃を予約し、予約を保持し打点/後続を改善する行動だけを攻撃前に許可する。攻撃可能な限り補助行動だけでENDしない。
- **RECOVER**: 直前のフーディンを失った再建状態（トラッシュにフーディン/ユンゲラーがいる）。アメ・ユンゲラー経由の再建、夜のタンカ、聖なる灰、必要エネルギーを優先し、スタジアム・妨害・不要な5体目は後回し。
- **LOCKED**: Powerful Handが効果無効/0ダメージ。改造ハンマーで即解除できるなら解除し、解除後に意味のある攻撃ができる時だけ使用。解除不能なら無意味なドローと攻撃を止める。対面名では判定せず盤面の効果・エネルギー状態から一般的に判定する。
- **ENDGAME**: 山札切れレースがきつい、または残りサイド1枚。`turns_to_deckout`と`turns_to_win`を比較して判定する。

## 攻撃予約

平坦なスコアで全行動を直接比較しない。

1. 現在提示されている最善の>0ダメージ攻撃を予約（`_attack_reserved`）。
2. 攻撃前候補ごとに「予約を保持するか（`_preserves_attack`）」「4つの許可カテゴリのいずれかで打点/後続/手札/妨害を改善するか（`_improves_plan`）」を評価。
3. 許可される候補だけを攻撃より上のTierに置き、それ以外は攻撃より下、ENDは攻撃予約中はブロック。
4. 各候補実行後は状態が再計算される（MAINは1選択ごとにエンジンが再照会するため、上位ログの「4〜5行動してから攻撃」が自然に再現される）。

## 動的山札管理

v8の固定フロア `max(8, サイド+3)` と `手札12・山札14` 固定停止は撤廃。実効山札を次から算出する。

- 現在の山札枚数
- ノココッチ循環で山札へ戻る枚数（ノココッチ+ノコッチ ≈ 2枚/体）
- 聖なる灰で山札へ戻るライン枚数（最大5）
- 残りサイド（`turns_to_win`、致死到達時はサイド分短縮）
- 毎ターンの強制ドロー（1枚/ターン）

任意ドロー/サーチの許可条件（`_optional_spend_ok`）:

1. 今ターンの致死（現在KO）を作る
2. 最初の後続フーディンを確定する
3. `turns_to_deckout > turns_to_win` を保つ

## ノココッチ（Run Away Draw = 3ドロー後に自身を山札へ戻す）

- 最後の1体のActiveノココッチが特性で消える自滅は必ず禁止。
- Activeノココッチは、ベンチに攻撃可能フーディンがいる時だけ、弱いActiveを退かして攻撃役を前に出す「攻撃への接続」として使用。
- ベンチのノココッチ（ドローエンジン）は、動的山札モデルが安全で、かつドローが現在の打点または後続を改善する時に使用。PRESSUREでは特性後も攻撃可能（Active不変）が基本条件。

## 退避

- 現在のActiveが意味のある攻撃をできず、ベンチに今すぐ攻撃できるフーディンがいる場合のみ退避。
- 攻撃可能なフーディンから盾へ退避して攻撃せずENDする行動は禁止。「次ターン倒されそう」だけでは退避しない。

## カード条件（すべて盤面情報から判定）

- **なかよしポフィン/ポケパッド**: 役割（攻撃ライン・次のケーシィ/ユンゲラー・最初のノコッチ・RECOVER要員）の不足を埋める時だけ。5体目の展開には使わない。
- **ふしぎなアメ**: 常時最優先にしない。今ターンの攻撃完成、RECOVER即再建、ユンゲラー経由が間に合わない時に高優先。通常はユンゲラー経由も許可し、アメを後続再建用に温存。
- **改造ハンマー**: 相手の特殊エネルギーを落とす実利益があり、使用後も予約攻撃・現在KOを失わない時だけ。
- **クセロシキ**: 盤面から判定（相手手札が多い/ミラー）。使用後も予約攻撃・現在KOを失わない時だけ。未使用・複数枚・形勢だけでは優先度を上げない。
- **スタジアム（バトルケージ）**: 相手スタジアムの上書き・攻撃/KO改善・ロック解除・明確な被害防止がある時だけ。
