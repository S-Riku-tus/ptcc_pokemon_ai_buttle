# 改善点対応表

| 改善テーマ | goal_v1 の扱い |
|---|---|
| ふしぎなアメから即攻撃・主力 KO | 同ターン KO 経路として列挙し、勝利・取得サイド順で選択 |
| フーディンが攻撃可能なのに終了 | v15/v22 の有効攻撃 END 安全規則を維持 |
| 場の非 ex より倒せるベンチ ex | 取得サイドを対象役割より上位にした辞書式比較 |
| 同じ ex の傷ついたベンチ個体 | 個体ごとに HP と KO 可能性を評価し、倒せる個体へボス |
| 相手デッキの主力を狙う | 同サイド候補では役割価値、エネルギー、進化段階等の既存評価で比較 |
| ターン開始直後の低価値ボス | 必要な経路行動を先にし、ボスを最後に固定 |
| オーロンゲ ex よりマシマシラへ早いボス | 場のオーロンゲ ex が明確な 2 発圏なら低サイドボスを抑止 |
| ノココッチの過剰ドロー | 現在 KO と 1 ターン以内の後続が揃った場合の停止を維持 |
| 山札が少ない場のノココッチ | 残り 1～2 枚かつ特性後にベンチフーディンで即 KO の場合だけ特性 |
| ノココッチにエネを付けて逃げる | 逃げコスト全額とベンチフーディンの即 KO を両方要求 |
| キチキギス ex を出す危険 | 終盤 2 サイド露出ゲートを維持し、単サイド循環エンジンを先に構築 |
| ケーシィのテレポート先 | ノコッチ系を盾にし、攻撃可能進化ラインと終盤キチキギス露出を分離する既存判断を維持 |
| 気絶後の昇格 | 即攻撃経路のフーディンを最優先、それ以外は単サイド盾を優先 |
| 改造ハンマー | ミスト等の効果無効を最優先。非ミストは即時攻撃阻止または KO 条件成立時のみ |
| クセロシキの使用範囲 | 大きい相手手札、複数保持、劣勢かつ他サポートなしの公開条件へ限定拡張 |
| ミスト・一時無効・フリーザー | ハンマー、ボス回避、キチキギス代替攻撃の既存経路を維持 |
| ロジックの交錯 | 対象決定を `goal_planner.py` に分離し、勝利・サイド階層をカードスコアから独立 |
| ML を一旦終了 | 実行時 ML、モデル JSON、特徴量処理を削除 |

この表は「関連する処理が存在する」だけでなく、goal_v1 でどの層が責任を持つかを示す。
対象と経路は目標プランナー、盤面展開と安全策は v15/v22 由来の決定論ポリシーが担当する。
