# alakazam_gpt_v1

> **軸について**: `alakazam_gpt_*`はChatGPTアプリ側で作成した外部由来の系統です。リポジトリ内の`alakazam_ml_*`とは別軸として管理し、バージョンはv1から独立に採番しています（旧`alakazam_ml_v34`＝本`alakazam_gpt_v1`）。本文中の`alakazam_ml_v29/v31/v32`は継承元である別軸エージェントを指します。

v1は、実戦championの`alakazam_ml_v31`とオフラインchallengerの`alakazam_ml_v32`を保存したまま、上位フーディンログの時系列未学習盤面に対する行動模倣を改善したchallengerです。

主な変更は、現在盤面だけでなく、その試合で直前に選んだ4判断、行動種類の累積回数、同一ターン内の判断位置、最後の攻撃・進化・給エネ・トレーナー使用からの経過ターンを、候補ランキングへ入力したことです。

## オフライン結果

Yushin Itoの同一60枚フーディンログ1,000試合から、999系列・49,590判断・443,714意味候補を再構成しました。episode ID順で70/10/20へ分け、最後の8,848判断は学習とearly stoppingに使用していません。

| 構成 | Validation Top-1 | Test Top-1 | Test Top-2 |
|---|---:|---:|---:|
| alakazam_ml_v32 提出モデル | 77.97% | 78.71% | — |
| alakazam_ml_v32 研究6モデル | 80.21% | 80.12% | — |
| **v1 sequence-state LambdaRank** | **80.81%** | **80.63%** | **93.30%** |
| v1 OOF residual selector | 80.94% | 81.09% | 93.61% |
| v1 leak-free GRU selector | 81.38% | 81.01% | 93.30% |

提出ランタイムには、validationとtestの双方で安定し、標準ライブラリだけで再現できる単一のv1 sequence-state LambdaRankを採用しています。研究selectorは小幅改善に留まり、PyTorch依存も必要になるため同梱していません。

目標のTop-1 90%は未達です。Top-2包含率は93.30%まで到達しているため、次の中心課題は候補生成ではなく、上位2候補を正しく並べ替えることです。
