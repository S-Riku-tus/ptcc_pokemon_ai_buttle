# alakazam_gpt_v3

> **軸について**: `alakazam_gpt_*`はChatGPTアプリ側で作成した外部由来の系統です。リポジトリ内の`alakazam_ml_*`とは別軸として管理し、バージョンはv1から独立に採番しています（旧`alakazam_ml_v36`＝本`alakazam_gpt_v3`）。本文中の`alakazam_ml_v29/v31`は継承元である別軸エージェントを指します。

v3はv2を基盤に、行動種ごとの候補集合をより詳しく表現するrich type gateを追加したchallengerです。

各行動種について、リーサル維持、手札増減、ドロー量、進化ルート不足の解消、対象状態、候補順序などを集約し、1,052値のruntime表現から356特徴を選択して行動種を分類します。提出runtimeは標準ライブラリだけで動作します。

時系列分離test Top-1は81.62%です。v2の81.60%から正解数は2判断増えましたが、差は+0.02ポイントにすぎず、実質的には同等です。目標90%は未達で、`alakazam_ml_v31`を実戦championとして維持します。
