# alakazam_ml_v13

v13は、公開ラダーで安定していたv11を土台に、上位フーディン2系統のログとv12の失敗例を反映した提出候補です。

## 主要変更

- ACE SPECを`Max Rod (1110)`から`Enriching Energy / リッチエネルギー (13)`へ変更
- ノコッチに貼る → ノココッチへ進化 → 特性で山札へ戻す再利用経路を実装
- 現在のバトル場を倒せるのに、低サイドのベンチをBossで呼ぶ誤りを禁止
- Mist Energyや正しく適用されるロケット団のフリーザー保護へ、0ダメージのPowerful Handを選ばない
- ロケット団のフリーザーの保護範囲を「たねのロケット団ポケモン」に限定
- 全対象が効果保護される場合、キチキギスexを別アタッカーとして完成させる
- 公開情報だけで見えたMist Energyの個体数を記録し、最後の改造ハンマーだけを条件付きで温存
- v12で広げたTeleport変更は採用せず、v11の攻撃継続を維持

## MLについて

`ranker_model.json`はv11と同一で、既定ではshadow-onlyです。アップロードされたZIPには学習基盤と教師データが含まれないため、再学習したとは扱っていません。`ml_features.py`にはリッチエネルギー循環・Mist公開枚数などの特徴を追加しており、将来の再学習で利用できます。
