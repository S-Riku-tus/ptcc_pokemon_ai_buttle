# alakazam_ml_v16

公開対戦33戦で22勝11敗・取得時レート907.5だったv15を親に、対戦ログで確認した
終盤判断と特殊ロックへの対処を追加した後継版です。60枚のデッキと学習済み
rankerはv15から変更していません。

## 判断の優先順

1. そのターンに勝てる攻撃を固定する。
2. 攻撃不能なら、進化で解除できるか、攻撃可能な控えを作ってにげられるかを調べる。
3. ボスの指令は現在の勝ち筋を壊さず、サイド価値の高いexを倒せる場合に使う。
4. 改造ハンマーは、使用後にも必要火力が残り、倒す相手自身以外へ意味がある場合に使う。
5. 必要なドロー・進化・エネルギーを行い、意味のある攻撃をENDより優先する。

オーロンゲ対面のベンチ制御は固定頭数ではありません。Shadow Bulletと
Adrena-Brainが同時に成立して新しい低HPポケモンを即座に倒せる場合だけ、役割が
重複する展開を止めます。二つ目のフーディン系統、最初のノコッチ、必要なシェイミは
常に展開候補として残します。
