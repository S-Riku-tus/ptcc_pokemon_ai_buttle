# alakazam_ml_v17

長期間レート880～920付近だったv15をChampionとして再採用し、公開ログで原因を確認
できた例外処理だけを追加した`v17-minimal`です。最初に作成したv16ベース版は、添付の
v15/v16比較を受けて土台から見直しました。

デッキ、ranker、特徴量、main、v15の検索・Boss・Hammer・進化・山札管理・ML担当範囲は
維持しています。v16の広いオーロンゲ制限、序中盤の行動停止、Teleport再採点などは
含めていません。

## 追加した例外処理

1. クマシュン型の「次の番、このポケモンはワザを使えない」を、対象個体とターン付きで
   記憶し、攻撃可能なベンチへ逃げます。
2. ホップのボクレー型の一時無敵を攻撃ログとコイン結果から復元します。表の場合だけ
   0ダメージ攻撃を拒否し、ボスの指令や有効な展開を選びます。
3. Activeフーディンへ1エネルギーを付ければ逃げられ、ベンチのフーディンが即時KOを
   取れる場合に限り、`attach → retreat → attack`を一経路として評価します。
4. ロケット団のフリーザーで全対象がPowerful Handを防ぐ場合、キチキギスexを3エネ
   まで集中育成し、完成後だけ前へ出してCruel Arrowを使います。ロケット団ポケモンが
   進化して保護対象外になった場合は、ボスの指令でその進化先を狙います。
