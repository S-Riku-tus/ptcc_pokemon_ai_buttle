# v17設計分析

## 1. なぜv16ベース初稿を作り直したか

公開結果はv15が33戦22勝11敗・取得時907.5、v16が60戦35勝25敗・取得時830.5です。
勝率差は標本誤差と先攻比率の影響を受けるため単独では決定的ではありません。しかし、
v15が長期間880～920付近で安定したこと、敗戦時のフーディン攻撃がv15約3.18回に対し
v16約2.48回、最終盤面が3.73体に対し3.08体だったことは、劣勢時の復元力を重視する
根拠になります。

両版はデッキ・ranker・特徴量が同一で、主差分はfallbackです。v16では約400行の変更が
同時に入り、検索増加が後続フーディン完成へ十分変換されていませんでした。このため、
最終v17はv15を土台に戻し、再現可能な失敗だけを移植する構成に変更しました。

## 2. v15から変えない領域

以下はテストでv15とのAST同一性を固定しています。

- `_backup_eta`
- `_deck_preserve` / `_deck_spend_ok`
- `_enriching_attach_score`
- `_hammer_target_score`
- `_score_play_trainer`
- `_score_play_poke` / `_score_to_bench`
- `_score_evolve`

また、v16で追加された`_grimmsnarl_bench_allowed`、`_ko_and_continuity_locked`、
`_abra_switch_score`が存在しないこともテストしています。これにより、v15の検索・妨害・
盤面再建の基本順序を意図せず変えません。

## 3. 一時状態を公開ログから復元する

攻撃不能と一時無敵は盤面のカード文面だけでは判定できません。v17は攻撃ログを読み、
対象の`(serial, cardId)`と有効ターンを保存します。

- 攻撃不能: ActiveにATTACKが提示されない時だけロックとして有効。
- コイン式無敵: 攻撃ログの後のコインが表の場合だけ有効。
- KO直後の`TO_ACTIVE`ではターン番号がまだ相手ターンなので、有効期限を次のMAINまで
  1ターン延ばす。
- 交代、進化、きぜつ、別個体への変化、期限切れで解除。

episode 87405053では強制昇格の観測からSplashing Dodgeの表を保持し、次のMAINで
Boss's Orders（option 7）を選びます。episode 87413112ではPowerful Handを拒否し、
エンリッチエネルギー（option 3）を選びます。

## 4. 多段ピボットを狭く扱う

「エネルギーを付ける」「逃げる」「ベンチで攻撃する」を別々に採点すると、最初の
エネルギーに価値を付けられません。そこで手札変化、逃げるコスト、攻撃コスト、実効
ダメージ、KO、取得サイドを仮想状態でまとめて評価します。

一方、汎用化すると2枚取りのキチキギスexを通常盤面で前に出す危険があります。通常時は
Activeフーディンからベンチフーディンへ移って即時KOできる場合だけに限定し、v15既存の
サポートポケモン退避処理は変更しません。フリーザーbreaker中だけ、完成キチキギスへの
交代を例外として許可します。

## 5. ロケット団のフリーザー

Powerful Handはダメージカウンターを置く効果なので、フリーザーのBasic Team Rocket
保護に止められます。Cruel Arrowは通常の100ダメージなので保護を通過します。v17は、
全公開対象が静的に保護された時に`ARTICUNO_BREAKER`を起動し、フリーザーが場を離れる
まで維持します。

1. キチキギスexを展開する。
2. 他のポケモンへエネルギーを分散せず3エネまで集中する。
3. 完成前には昇格させない。
4. 完成後にActiveを逃がし、Cruel Arrowでフリーザーを狙う。
5. スパイドプス等へ進化した個体はBasic-only保護外なので、Boss＋Powerful Handの
   短期経路として優先する。

## 6. 検証からの判断

最終候補はv15に520-480、修正前のv16ベースv17に524-476でした。対オーロンゲは
249-151で、v15対照253-147とほぼ同水準です。したがって、追加例外を維持しながら
v15の通常時の性質へ戻す判断には、ローカル対戦上も反対材料がありません。

ただし、フリーザー専用の大規模ローカル対戦母集団はありません。HP120のフリーザーは
Cruel Arrowを通常2回必要とするため、対策は相性差を緩和するもので、勝利を保証する
ものではありません。
