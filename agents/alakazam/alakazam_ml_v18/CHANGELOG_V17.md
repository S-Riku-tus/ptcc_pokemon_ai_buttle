# v17変更一覧

## 最終版の土台変更

- 親agentをv16からv15へ変更。
- v15の`deck.csv`、`ranker_model.json`、`ml_features.py`、`main.py`を維持。
- v15の検索、Boss、Hammer、進化、山札、復元系の主要9関数をAST単位で同一に固定。

## v15へ追加したもの

- 攻撃不能攻撃のログ記憶と、攻撃可能な控えへの退避。
- コイン依存・1ターン完全無敵の個体単位記憶。
- 無効対象へのPowerful Hand/Cruel Arrow拒否とBoss escape。
- Activeフーディンからベンチフーディンへの即時KO限定ピボット。
- 永続`ARTICUNO_BREAKER`状態、キチキギスexへの3エネ集中、完成後の昇格。
- ロケット団の進化ポケモンをフリーザー保護外のBoss対象として加点。

## v16ベース初稿から外したもの

- オーロンゲ対面の広範なベンチ制限。
- `_ko_and_continuity_locked()`による検索・特性・進化の横断停止。
- 山札レース予測による序中盤の追加制限。
- Teleportation Attackの対象評価全体の書き換え。
- BossとHammerのv16追加再採点。
- オーロンゲ盤面でのML全面停止。
- 一般的なチップダメージ目的の多段ピボット。

## 安全境界

- 一時無敵は静的な効果防止と分離し、1ターン回避だけでフリーザー計画を起動しない。
- 通常盤面の新規ピボットはフーディン同士の即時KOだけ。
- キチキギスexはフリーザーbreakerが起動し、かつ攻撃可能な時だけ昇格。
