# Changelog v16

- v15の60枚とrankerをそのまま継承。
- クマシュンなどの「次の番に攻撃できない」攻撃をカード文面から検出し、対象個体と
  ターンを記憶。進化または交代後は解除する。
- 攻撃不能時は、攻撃可能な控えへのエネルギー供給、進化解除、にげるを通常行動より
  上位に配置。
- 改造ハンマー使用後のPowerful Hand火力を再計算。倒すバトル場自身への無駄打ちと
  手札1枚減少でKOを失う使用を禁止。
- 現在のバトル場を倒して勝てる場合、非勝利のボスの指令を禁止。通常時もサイド枚数を
  明示的に評価してexを優先。
- 効果を受けない相手だけが残る場合、無効なPowerful Handを拒否し、ハンマー、ボス、
  Fezandipiti exの通常ダメージ攻撃へ移行。
- ケーシィのTeleportation Attack後はノココッチ、ノコッチを優先。フーディン系統は
  相手の次ターンの被KO可能性を差し引き、キチキギスexは相手サイド5枚以上の序盤だけ
  壁として高く評価。
- オーロンゲ対面は固定4体制限を廃止。Shadow Bullet 30とAdrena-Brain 30が同時に
  成立する場合だけ、重複する低HPベンチを抑制。
- 山札消費を残り勝利ターンと比較し、勝利確定または山札危機以外では序中盤の展開を
  止めない。
- オーロンゲ系統が見えている局面はMLより戦術ルールを優先。
- v16診断カウンタと15件の専用Goldenテスト、対戦差分解析スクリプトを追加。
