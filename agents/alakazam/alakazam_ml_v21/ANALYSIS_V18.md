# v18設計分析

## 1. 出発点

v17の公開60戦は39勝21敗、勝率65.0%、レート833.1でした。
初攻撃は勝敗でほぼ同じ一方、敗北では初攻撃後の非攻撃ターンと、
ケーシィ／ユンゲラーによる代替攻撃が増えていました。

ただし、ログから直接因果を確認できた重大な誤判断はBossの3件です。

| Episode | v17の選択 | 確定していた上位ルート |
|---:|---|---|
| 87597062 | RioluをBoss | Hammerで防御解除しHP340 ActiveをKO |
| 87486591 | HariyamaをBoss | リッチ＋フーディン進化で手札17、HP340 ActiveをKO |
| 87498561 | MakuhitaをBoss | Dawnで手札23、HP440 ActiveをKOして勝利 |

共通原因は対象ポケモンの固有名ではありません。Bossが「今の手札で倒せる対象」を
単体評価し、Bossを使わない場合に同一ターンで到達する最終打点を比較していないことです。

## 2. 採用した設計

`_active_route_plan()`は次の条件を満たす行動だけを候補にします。

1. 現在のMAIN選択でゲームエンジンが提示している。
2. 結果が確定しており、未知のドローへ依存しない。
3. Powerful Handの手札枚数へ変換できる。

扱う確定差分は次のとおりです。

| 行動 | 手札差分 | 山札消費 |
|---|---:|---:|
| 改造ハンマー | -1 | 0 |
| ノココッチ特性 | +3 | 3 |
| リッチエネルギー | +3 | 4 |
| フーディン進化 | +2 | 3 |
| ユンゲラー進化 | +1 | 2 |
| アメ＋フーディン | +1 | 3 |
| Dawn | +2 | 3 |
| Hilda | +1 | 2 |

複数Supporter、同じ進化先、手札にある枚数を超えるカード利用は除外します。
最大でも小さな部分集合探索で、実測は約1.3ms/decisionでした。

## 3. Bossの比較規則

Boss対象のKOが成立しても、Active維持ルートが確定KOなら次を先に比較します。

1. Activeルートがゲーム勝利か。
2. Activeルートの取得サイドがBoss対象より多いか。
3. 同サイドなら既存の役割・投資・脅威評価。

この順序により、固有カード名を増やさずに3件を同じ規則で修正できます。
一方、Activeを倒せずBoss対象で勝てる場合や、防御をHammerで解除できない場合は
従来どおりBossを許可します。

## 4. 終端勝利ゲート

episode 87485511では、ノココッチ特性が使えなかった直接原因は
相手スタジアムによる特性ロックでした。v17はスタジアム除去後に正しく特性を使い、
フーディンを前へ出しています。

残った問題は、相手ベンチなしの確定KO後もポフィンなどを挟めることです。
v18は次を実装しました。

- 攻撃がすでに提示されている場合、攻撃以外を拒否。
- Activeノココッチの特性後にフーディンで盤面全滅できる場合、特性を最優先。
- 特性が未提示なら、盤面・山札条件からロック理由を診断へ記録。

## 5. 撤回したP1

「初回攻撃後、後続フーディンがいなければ再建を最優先」という広い規則も試しました。
しかしv17との200戦で65-135、診断上2,895回発火しました。

敗北ログの後続不足は強い相関ですが、個々のMAINで検索・進化・追加展開を
どこまで強制すべきかは因果として確定していません。固定スコアへ変換すると、
現在の攻撃役維持や通常の手札形成まで壊します。そのためv18から完全に除外しました。

次に攻撃継続へ取り組む場合は、1ターンの手札差分ではなく、
相手KO後の昇格と次ターンのエネルギーまで含む2ターン状態探索が必要です。

## 6. 結論

v18は「広く賢くする」版ではなく、公開ログで因果が確認できた誤判断を
一般化して塞ぐ版です。1,000戦ミラーはv17へ505-495で、改善の統計的証明には
なりませんが、通常性能を維持しながら対象局面の選択を変えられています。
