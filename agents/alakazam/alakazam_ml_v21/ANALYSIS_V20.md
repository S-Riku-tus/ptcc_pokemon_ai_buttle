# v20実装判断

## 実装順

1. 残り2/3サイドの勝ち確Bossを独立した絶対ゲートにした。
2. ターゲットの戦略価値を計算し、到達可能性を混ぜずに並べた。
3. Active専用ルート探索を任意ターゲットへ一般化した。
4. 選択済みターゲットと必要手札をドロー評価へ渡した。

この順序により、高HPの高価値対象が到達不能でも、低HPの次点を探索できる。
BenchルートではBossとDawn/Hildaを同時使用できず、BossとHammerを使う場合は
Powerful Handの手札が2枚減る。

## 手札停止の境界

当初は「選択ターゲットを既に倒せる」だけでRun Away Drawを止めたが、
v19 mirror 500戦で223-277まで後退した。これは既知の
「一律デッキアウトガードがcabt勝率を下げる」問題と同型だった。

最終版は次の全条件を要求する。

- 選択ルートにHammer、進化、追加ドロー等の前提行動が残っていない。
- Activeなら今すぐ攻撃、BenchならBossを使うだけでKOできる。
- 攻撃時手札が`ceil(残HP/20) + 5`以上。
- 攻撃可能なAlakazamがいて、エネルギー枯渇中ではない。

これにより「必要枚数ぴったり」は次ターン用バッファとして維持し、
明確なoverdrawだけを抑える。Xerosicは3枚固定へのリセットなので、
追加バッファによる防御は行わない。

## リスク

- target priorityの重みは公開ログから直接学習した値ではなく、サイドレースの
  順序を安定させる決定論的ヒューリスティックである。
- v20-v19 mirrorは最終500戦で49.0%の互角範囲。ex主体メタでの改善は
  Kaggle提出後に確認が必要。
- 上位方策一致率は60.782%から60.553%へ低下した。勝ち確Boss見送りなど、
  今回修正対象とした意図的差分を含むため、単独の不採用条件にはしていない。
