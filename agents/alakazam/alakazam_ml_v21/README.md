# alakazam_ml_v21

`alakazam_ml_v20`の公開ラダー64戦を主根拠に、デッキ60枚と学習済みモデルを
固定したまま、実戦で損失になっていた意思決定を修正した版です。目標はレート
900での安定、上振れではなく方策の再現性が得られた場合に1000帯へ届くことです。

## v21の重点

- 今の攻撃対象を倒せる手札が確定した後は、ノココッチの「にげあしドロー」を
  原則止めます。唯一の攻撃役しかおらず、次のフーディン系列もない場合だけ、
  継戦準備として例外を認めます。
- ケーシィの攻撃後の交代と、気絶後のバトル場昇格を別の問題として評価します。
  前者はノコッチ > ノココッチ > 安全なキチキギスex > フーディン系列、
  後者は次のターンに攻撃できるフーディンを最優先し、それ以外は
  ノコッチ > ノココッチ > キチキギスex > 進化ラインです。
- 実際にダメージまたはダメカンを与えられる攻撃が提示されているときは、
  攻撃せずENDを選びません。ミストエネルギー等で効果が0になる攻撃は強制しません。
- 相手残りサイド3枚以下では、キチキギスexを原則ベンチに出しません。
  直前に自分のポケモンが気絶し、3枚ドローが即KOまたは攻撃復帰を作る場合だけ
  例外にします。
- 相手の見えている進化系列をカードメタデータから動的に推定し、サイド枚数、
  エネルギー、どうぐ、特性、現在HPと合わせてボスの司令の対象価値を決めます。
  ケーシィ、ジュラルドン、リオルなど「主力を成立させる進化前」も評価対象です。

## 実戦ログ再評価

v20の64戦・3,996判断を同じ観測状態で再生しました。

- ノココッチ特性選択: 93回 → 74回
- ケーシィの交代でノコッチを選択: 5回 → 18回
- 気絶後にノコッチを昇格: 15回 → 98回
- 気絶後に次ターン攻撃可能なポケモンを昇格: 41回
- 相手残り3枚でのキチキギスex展開: 1回 → 0回
- 3,996判断中、意味上の変更は170判断

これはteacher-forcedの反実仮想再評価であり、v21自身の公開ラダー成績では
ありません。ローカル対戦100戦は50-50でしたが、採用根拠ではなく
クラッシュ・不正手が0であることだけを安全性確認に使っています。
