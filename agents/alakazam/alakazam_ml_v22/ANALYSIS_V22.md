# フーディン v22 分析

## 結論

v22は、Rating 721.5だったv21を改修したものではない。提出ID `54976903`
の最新版v20をコード・デッキ・モデルのSHA-256まで照合し、その実体から直接
分岐した。

今回の中心課題は初動速度でも最大手札でもなく、最初のフーディンが倒された後も
攻撃列を切らさないことである。

```text
現在の攻撃
  + 1ターン以内に攻撃できる後続
  + 再利用できるノコッチ循環
= 攻撃列
```

## 1. v20の再評価

最新版run2の56リプレイをローカル解析すると、次の値だった。

| 指標 | v20 run2 |
|---|---:|
| 初回攻撃 | 自分の第2.32 MAINターン |
| 攻撃機会からの攻撃変換 | 208 / 223 = 93.27% |
| Boss使用後の同ターン攻撃 | 35 / 35 |
| フーディン系攻撃 | 170回 |
| 盤面切れ負け | 4 |
| 山札切れ負け | 3 |
| Archaludon | 4勝9敗 |
| Marnie's Grimmsnarl ex | 0勝4敗 |

したがって、次の全面改修は行わない。

- 初回攻撃を無理に早める
- 攻撃可能なら条件を見ずに強制攻撃する
- Boss、改造ハンマー、クセロシキを全面的に組み直す
- 手札枚数だけでノココッチを止める

攻撃を選ばなかった12件の多くは、ロケット団のフリーザー、ミストエネルギー、
一時的な完全無効など、攻撃選択肢は表示されても実効ダメージがない局面だった。
v20の効果無効判定を残す方が安全である。

## 2. 上位ログとの差

添付分析の追加上位8代表は1,625試合で、4代表がv20と同一60枚だった。

| 指標 | v20 run2 | 追加上位8代表 |
|---|---:|---:|
| 総攻撃/試合 | 3.47 | 4.96 |
| フーディン攻撃/試合 | 2.84 | 4.30 |
| ノココッチ特性/試合 | 1.13 | 4.40 |
| Powerful Hand時の手札 | 13.17 | 12.40 |
| フーディン攻撃4回以上 | 34.5% | 64.1% |
| T2盤面5体以上 | 49.1% | 71.8% |

上位は手札を極端に大きくしているのではない。約12枚の火力を維持しつつ、
ケーシィ2～3本、ノコッチ1～2本、次の超エネルギーを並列に作っている。
一方v20は山札を20枚以上残す試合が約半数あり、山札を盤面と攻撃回数へ変換
できないまま終わる割合が高い。

キチキギスexについても結論を修正した。追加上位8代表のキチキギス攻撃は
0.03回/試合である。一般対面で第二アタッカーとして育てることは普遍的な強さ
ではないため、v22ではv20の「復旧役、ロック解除時のみ攻撃役」を維持する。

## 3. v21が落ちた理由の扱い

v21のRating 721.5を踏まえ、次の補正を継承しなかった。

- 現在の確定KOだけを見てノココッチを広く停止する
- 一律の高手札上限でHilda、Dawn、Poké Padまで止める
- 進化系統名からBoss価値を広く推測する
- キチキギスexへ段階的にエネルギーを投資する
- きぜつ後と技による交代を同じ優先順位で扱う

これらは単独では合理的でも、同時に作用すると盤面展開、後続探索、ターゲット
変更が互いに干渉する。v22では各補正を一つの責務に限定した。

## 4. v22の変更

### 4.1 ノココッチ

`backup_eta`を公開情報だけで評価する。

- 完成済み後続: 0
- 次ターンに進化/給エネして攻撃: 1
- ケーシィ→ユンゲラー→フーディンの通常進化: 2
- 必要札が公開情報で揃っていない: 99

`backup_eta > 1`なら、現在のKOが成立していてもノココッチを20,500点へ上げる。
これは手札増加ではなく後続探索である。

逆に、現在の有効攻撃、`backup_eta <= 1`、エネルギー、必要火力に2枚の余裕、
手札10枚以上がすべて揃った時だけ、ベンチのノココッチを止める。v21のような
「確定KOなら即停止」にはしていない。

### 4.2 ノコッチ再展開

フーディン系が2体以上いて、場からノコッチ系が消えている時は、冗長な3本目の
ケーシィより最初のノコッチを優先する。2本目以降は従来の上限を維持する。

相手サイド3以下かつベンチ攻撃が見えている終盤は、すでに1本あるなら追加の
70HPノコッチを出さない。Grimmsnarl/Froslass戦の多重取りを抑えるためである。

### 4.3 後続への先貼り

現在のフーディンが有効に攻撃でき、ベンチのケーシィ/ユンゲラーに公開情報上の
進化経路があり、他に完成済み後続がない場合、基本超エネルギーまたはテレパス超
エネルギーを先に貼る。

同ターンの場フーディン給エネは28,000点のままで最優先、後続先貼りは18,400～
18,600点で、その下に置いた。確定KOを割る場合はv20の手札消費ゲートが止める。

### 4.4 ふしぎなアメ

v20にはすでに、ふしぎなアメで同ターン攻撃/KOを作る経路評価がある。
即KOは33,000点、初回攻撃加速は23,500点であり、Boss経路評価とも接続済みだった。
ここは変更せず、v22の後続先貼り・昇格と組み合わせたGolden-stateを残した。

### 4.5 きぜつ後昇格と技による交代

二つを分離した。

- きぜつ後: 次ターン攻撃できるフーディン系を最優先
- 攻撃経路がない: ノコッチ → ノココッチ → 安全な序盤キチキギスex
- ケーシィ/ノコッチの交代技: 技でターンが終わるため、攻撃役ではなく盾を選ぶ
- キチキギスex: 相手サイド5以上かつ見えている攻撃で倒されない時だけ盾候補
- 危険なキチキギスexより、単サイドの進化ラインを選ぶ

### 4.6 主要エンジンの狙撃

v20の役割表、サイド枚数、エネルギー、どうぐ、進化段階、同ターンKO可能性を
そのまま使う。広い進化系統推測は復活させない。

唯一、Grimmsnarl/Froslass盤面で悪エネルギーが付いたマシマシラを
Adrena-Brain稼働中のエンジンとして上げた。悪エネルギーがなければ単独の
ユキメノコを優先できる程度に留めている。

## 5. 変更しなかったもの

- 60枚デッキ
- 学習済みLightGBM、274特徴量、50木
- confidence threshold 0.37
- MLの担当範囲
- Boss、改造ハンマー、クセロシキ、ミスト記憶
- ロケット団のフリーザー、一時無効、攻撃不能からの退避
- 山札フロア、最後の1体ノココッチ禁止
- 現在の確定KOを手札消費で壊さないゲート

MLはベンチ役割と同一進化カードの対象選択しか直接制御しない。今回の主要課題は
特性、給エネ、昇格、交代、Bossなので、モデルを再学習しても直接は直らない。
ルールで安全性を保証し、MLの既存範囲を固定する方が再現性が高い。

## 6. リプレイ差分

最新版v20の3,046判断へv20とv22を同時に適用したteacher-forced比較:

- 意味一致: 96.29%
- 意味変更: 113判断
- MAIN: 53
- きぜつ後/空いた場への昇格: 46
- ケーシィの交代: 9
- ノコッチの交代: 4
- Boss対象: 1
- 例外/クラッシュ: 0

これは勝率の推定ではなく、補正が意図した局面に限定されているかを見る監査である。
実戦Ratingの改善は新しい提出ログでのみ判定する。
