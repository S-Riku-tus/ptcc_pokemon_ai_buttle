# v22設計分析

## 結論

v22は、v21の安全化を撤回する版ではありません。v21が解決した山札切れ、無効攻撃、終盤のキチキギスex露出、昇格ミスを維持しながら、**安全判定を「現在のKO」から「現在＋次の攻撃」へ広げた版**です。

上位2者とv21は同じ60枚でした。差は、v21のPowerful Hand時平均手札が15.60枚と大きい一方、総攻撃3.88回、ノココッチ1.46回に留まることでした。上位は手札12.11～12.56枚で総攻撃5.33～5.67回、勝利試合でもノココッチを2.94～3.13回使っています。

したがってv22では、最大手札ではなく次を最適化します。

1. 今ターンの実効攻撃
2. 次ターンの攻撃可能性
3. 必要十分な手札
4. 明示的な第二攻撃経路
5. 山札寿命

## 1. ノココッチ停止条件の修正

v21の継戦例外は、攻撃可能フーディンが1体、`backup_eta > 1`、さらに場にケーシィ・ユンゲラー・追加攻撃役が全くないことを要求していました。

このため、場にケーシィだけ存在し、手札にアメ・フーディン・エネルギーがない状態でも、後続があるとみなして循環を停止することがありました。

v22では、見えている進化前の数を使わず、次だけで判定します。

```text
backup_eta <= 1 なら後続完成
backup_eta > 1 なら後続未完成
```

現在のKOが最終勝利でなく、山札が動的フロアより4枚以上多い場合、後続未完成ならノココッチを現在のKOより先に使います。

## 2. 13枚のソフト手札目標

上位のPowerful Hand時平均は約12～13枚でした。v22は13枚を任意ドローの目標にします。

ただし、13枚は上限ではありません。以下ではさらに引きます。

- 現在のActiveを倒す打点に不足
- 攻撃役がいない
- `backup_eta > 1`
- 超エネルギー不足
- 最初のフーディンが未完成

逆に、現在の攻撃と1ターン以内の後続が成立している場合は、ノココッチ、ヒルダ、ヒカリ相当のDawn、ポケパッド、リッチエネルギーによる任意の上積みを止めます。

## 3. 循環後のノコッチ再展開

ノココッチ特性は自身と進化元、付属カードを山札へ戻します。特性を使った後にノコッチを再展開しなければ、循環は1回で終了します。

v22は、

- ノコッチ／ノココッチが場に0
- 現在の攻撃役が完成済み
- `backup_eta > 1`

の場合、ノコッチの展開を追加ケーシィより上へ置きます。最初の攻撃役がない序盤では従来どおりケーシィ優先を維持します。

## 4. キチキギスexの複線化

v21はキチキギスexをドロー役としては使いますが、通常は3エネルギー攻撃の一歩手前まで育つまで給エネしません。結果としてv21ログではキチキギス攻撃が0回でした。

v22は、次の具体的な目標があるときだけ複数ターンの育成を許可します。

- HP100以下の2サイドまたは重要エンジン
- Powerful Handが効果無効で、Hammerもない
- ロケット団のフリーザーによる全対象保護

さらに、通常対面では次を要求します。

- 現在攻撃可能なフーディンがいる
- `backup_eta <= 1`
- 今ターンActiveフーディンへ超エネルギーを貼る必要がない
- 相手残り2サイド以下で、まだ0～1エネルギーなら開始しない

これによりMajkel型の第二経路を取り込みながら、v11系で起きた「キチキギスへ給エネして本線を失う」退行を避けます。

## 5. MLを再学習しなかった理由

現在のMLが上書きできるのは、安全なケーシィ／ノコッチ展開と同じ進化カードの対象選択です。

今回変更した、

- ノココッチ特性
- 任意ドロー停止
- エネルギー配分
- キチキギス攻撃経路
- 気絶後の攻撃可能判定

はすべてルール側の担当です。モデルを再学習してもライブで反映されないため、v22ではモデルを固定し、因果関係をロジック差分へ限定しました。

## 6. 提出後に見るべき指標

Ratingだけでなく、最低50戦、可能なら100戦以上で次を比較してください。

- 総攻撃／試合
- フーディン攻撃／試合
- 勝利試合のノココッチ回数
- Power Hand時平均手札
- 初攻撃後の非攻撃ターン
- `backup_eta > 1`で最初のフーディンを失った回数
- キチキギスへの給エネ回数とCruel Arrow変換率
- 山札切れ率
- キチキギスexを2サイド取りされた敗戦

期待する方向は、手札15.6枚をさらに増やすことではなく、手札12～14枚程度を保ちながら、総攻撃とフーディン攻撃を増やすことです。
