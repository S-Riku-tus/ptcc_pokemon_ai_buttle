## 狙い

v20は初回攻撃2.32ターン、攻撃機会変換93.27%、Boss後攻撃35/35で、初動と
攻撃終端はすでに強い状態でした。一方、上位ログとの差はフーディン攻撃回数と
後続盤面に集中しています。

v22は次の順で攻撃列を作ります。

1. 今ターンの有効攻撃を成立させる
2. 次ターンに攻撃できるフーディン系へ先に超エネルギーを貼る
3. 後続が1ターン以内に完成しない時だけノココッチを強く使う
4. ノコッチが循環後に消えたら、冗長なケーシィより先に1体戻す
5. きぜつ後は攻撃できる進化ライン、できなければ単サイド盾を出す

## 方針

- デッキと学習済みモデルはv20のまま
- 一般対面のキチキギスexは復旧役で、第二アタッカーとして段階育成しない
- ふしぎなアメ即攻撃、Boss、ハンマー、効果無効対策はv20を維持
- マシマシラは悪エネルギー付きでAdrena-Brainが稼働した時だけ優先度を上げる
- 終盤のベンチ攻撃対面では余分な低HPポケモンを並べない
