# フーディン v23 対象選択分析

## 結論

v23はv22の連続攻撃・バックアップ育成を維持し、今回の問題を
「ボスを使うか」と「使った後に誰を前へ出すか」の二段階に分離した。

実装は純粋なML置換ではない。勝利、同ターンKO、獲得サイド差、攻撃無効、
ボス使用後の手札減少は決定論で保証し、同じサイド階層にいる候補の
エンジン価値だけを上位ログから学習した線形順位モデルで補正する。

## v22は何をしていたか

v22のボス関連処理は決定論だった。

1. `_target_priority_score` がサイド、役割、進化段階、エネルギー、
   道具、HPを加点する。
2. `_ko_route_plan` がボスを1枚使った後の手札で同ターンKOできるかを調べる。
3. `_boss_target_score` が、場のポケモンをそのまま倒す場合より
   十分に価値が高いかを再判定する。
4. ボス解決中の `SWITCH` は `playerIndex` が相手側なら
   `_gust_value` へ送る。

つまり「対象評価が存在しない」のではない。ただし対象価値が複数の関数へ
分散し、次の問題が残っていた。

- KO可能なexに対する追加の賞品差がなく、個別カードの役割加点に
  逆転される余地がある。
- MAINのボス使用判定と、ボス解決後の対象順位が同じ優先尺度を
  完全には共有していない。
- 現在のアクティブをKOできる時の安全ゲートが強く、ベンチexも
  同時にKOできる盤面でボスが「不要」と判定される経路がある。
- `SWITCH` という同じコンテキストを自分の交代にも相手へのボスにも使うため、
  将来の修正で再び混線しやすい。

## 上位ログから作れる教師データ

使用データは次の1,689戦。

- Majkel: 1,000戦
- Yushin旧アーカイブ: 178戦
- Yushin最新版: 511戦

ボス使用後の対象選択では、ログに「選んだ1体」しか残らなくても問題は小さい。
その選択画面には合法なベンチ候補がすべて並ぶため、1局面を
「選択された候補 > 選択されなかった各候補」というペアワイズ順位データへ
変換できる。

抽出結果:

- 対象選択: 1,559局面
- 候補ポケモン: 6,257体
- 学習ペア: 2,678組
- 時系列後方ホールドアウト: 312局面

カードIDを直接覚えさせず、次の16特徴量だけを使った。

- サイド価値、勝利KO、同ターンKO
- ex / Mega ex、進化段階
- エネルギー、道具、残りHP、受けたダメージ、逃げにくさ
- 攻撃準備済み、特性、エンジン特性、保護特性

ホールドアウトTop-1は全対象で57.7%、KO候補がある局面で58.1%だった。
単純な「勝利→KO→サイド枚数」規則はそれぞれ22.9%、21.0%だった。
モデルは完全ではないが、同階層の役割比較には明確な追加信号がある。

## なぜ全面ML化しないか

MAINでボスを使うかどうかは、候補がすべて明示される対象選択より難しい。
ログの一手だけを正解にすると、先に進化・ドロー・エネルギー付与を行い、
後で同じターンにボスを使う手順まで誤って負例になる。また、上位プレイヤーの
癖やデッキ分布も教師へ混ざる。

実際、「場の単賞品を倒せ、ベンチexもボス後にKOできる」という広い条件は
591局面あったが、上位勢がそのターンにボスを使ったのは235局面だった。
フロスラス、フーディン、ロケット団のフリーザーなど、単賞品でも
盤面エンジンを止める方が高価値な例がある。したがって
「見えたexへ常にボス」は上位ログとも一致しない。

## v23の意思決定順

1. 現在のアクティブKOで勝つならそのまま勝つ。
2. ベンチex/Mega exをボス後の実手札で同ターンKOでき、
   現在の普通の単賞品よりサイドを多く取れるならボスを強く優先する。
3. ただし現在の単賞品が明示的な中核エンジンなら、強制せず総合評価を残す。
4. ボス解決後は、効果カードがボスかつ対象所有者が相手であることを
   通常の自分側交代より先に判定する。
5. 勝利KO、KO可否、サイド階層を決定論で並べる。
6. 同じ階層だけ、学習済み役割スコアを最大±800で加える。

学習補正はサイド階層を逆転できない。未知カードやモデル読込失敗時も
決定論だけで合法手を返す。

## 変更範囲

- デッキ60枚はv22と同一。
- 既存LightGBM行動ランカーとその適用範囲はv22と同一。
- v22の連続攻撃、ノコッチ再建、バックアップ先貼り、昇格・盾選択を維持。
- 新規MLはボス対象の同階層タイブレークだけ。

## 限界

- 教師強制再生は変更後の反実仮想な試合展開や勝率を示さない。
- 上位の一手も絶対的な正解ではなく、プレイヤー固有の方針を含む。
- 新しい実戦レートは未測定であり、900/1000安定は目標であって保証ではない。
