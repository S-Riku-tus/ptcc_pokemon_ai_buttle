# alakazam_ml_v24

v23の実戦50ログと、リーダーボード3位 Yushin Ito の1000ログを盤面単位で比較して作成したv24です。デッキ60枚と既存の行動ランカーは変更せず、実戦で確認できた「標的選択」と「場のノココッチ停止」を限定的に修正しています。

主な変更:

- 場の通常ポケモンまたは倒せないexより、ボス後に確実に倒せるベンチex/Mega exを優先
- 同じexが場とベンチにいて、傷ついたベンチ側だけ倒せる場合もボスを選択
- オーロンゲexを明確な2発圏内に入れている間は、序盤のマシマシラ等1サイドへのボスを抑止
- ただしオーロンゲexを2発で倒せない場合、マシマシラKOをフォールバックとして維持
- 山札1～2枚で場のノココッチが止まる場合、特性で山札へ戻ってフーディンを出し、同ターンKOへ移行
- ノココッチに既に2エネあり、3枚目のエネを付ければ逃げてKOできる合法盤面では、エネ付与→逃げるルートも選択
- Yushin Itoの1000戦から再学習したカードID非依存の標的ランカーを、決定規則を上書きしない±800の補助値として使用

詳細は `ANALYSIS_V24.md`、変更一覧は `CHANGELOG_V24.md`、検証結果は `VALIDATION_REPORT_V24.md` を参照してください。
