# alakazam_ml_v25

レート約850を再現したv24を骨格のまま残し、旧v25（実測約767）の回帰要因をすべて除去して作り直したエージェントです。2本のv24提出計117戦、Majkel1337の1000戦、Yushin Itoの1000戦を比較し、実戦ログで繰り返し確認できた差だけを修正しています。デッキ60枚、行動ランカー、標的ランカーはv24から変更していません。

主な変更:

- 旧v25の「気絶後に未完成フーディンラインを昇格」「ミラーでフェザンディピティを原則出さない」を完全撤回
- ノココッチの「3枚引く」だけでなく、ノココッチ・ノコッチ・付属カードが山札へ戻るところまで計算し、実際の循環後山札枚数で安全判定
- 山札0枚でも、盤面に別のポケモンがいて循環後に2枚以上へ戻る場合は、特性を使って次のドローを確保
- バトル場のアーチャルドンexを倒せるのに、役割ボーナスだけでエースバーンへボスを使う判断を抑止
- アーチャルドンexが明確な2発圏内なら、勝利確定のボスを除き、エースバーンや代替の1枚取りへ圧力を逃がさない
- ユキメノコが場にいる間は、エネルギー付きマシマシラより継続ダメージ源のユキメノコを優先

最終検証では、v24再提出57戦の3,574判断に対する変更は1.15%です。一方、トップ1000戦では変更判断の大半がトップの実行手と一致し、ローカルのv25対v24・200戦は114勝86敗、クラッシュ・不正手・攻撃可能ENDはいずれも0でした。

詳細は `ANALYSIS_V25.md`、変更一覧は `CHANGELOG_V25.md`、検証結果は `VALIDATION_REPORT_V25.md` を参照してください。v24の文書も、骨格と比較根拠を残すため同梱しています。
