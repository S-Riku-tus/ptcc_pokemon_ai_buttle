# alakazam_ml_v26

ラダー 57 戦で 36勝21敗（63.2%）だった v25 を骨格のまま残し、その 21 敗を全数分解して
残っていた 2 クラスだけを潰したエージェントです。デッキ 60 枚、行動ランカー、標的ランカーは
v24 から一度も変更していません。

v25 の 21 敗のうち **7 敗が「自分の盤面ポケモンが 1 体以下」から始まっており、そのうち 5 敗は
盤面を増やす合法手が手札に残ったままでした**。もう 1 つは v24 から一貫して負け越している
オーロンゲ（Marnie's Grimmsnarl ex）対面で、3 本のラダー合計 8/27 = 29.6% です。

主な変更:

- 盤面が 1 体以下のときは、body を増やす手（ポフィン / たねポケモン / ポケパッド /
  フェザンディピティ ex / シェイミ）を致死維持ゲートより前で最優先にする
- 盤面 1 体以下で body を増やせる限り、ターンを終えない
- Run Away Draw は 2 体 → 1 体になる循環も拒否する（勝利・同ターンKO・body 補充可能時を除く）
- 場に進化元がいないときは、ヒルダ（進化サーチ）よりヒカリ（たねサーチ）を優先する
- 相手盤面の**進化先**まで見てベンチ狙撃を先読みし、露出 2 体以上・自盤面 3 体以上なら
  シェイミ（フラワーカーテン）を先に置く
- ポケモンチェックでダメカンをばらまく特性（ユキメノコ）は、サイドが同数以上で
  こちらの特性持ちが 2 体以上課税されているとき、バトル場と同格の KO 対象としてボスで釣る

teacher-forced 再生では v25 の 3,432 判断のうち変更は **15 件（0.44%）** で、うち 14 件が
「盤面 1 体以下」の局面です。変更が出た 10 試合中 8 試合が敗北試合でした。
ローカルでは v25 とのミラー 400 戦が 50.0%、`marnies_grimmsnarl_ex_v7` との 1,800 戦が
72.11%（v25 は 70.22%）、汎用 5 対面 500 戦が 469 勝（v25 と同値）で、クラッシュ・不正手・
board collapse はいずれも 0 です。

詳細は `ANALYSIS_V26.md`、変更一覧は `CHANGELOG_V26.md`、検証結果は `VALIDATION_REPORT_V26.md`
を参照してください。v24 / v25 の文書も、骨格と比較根拠を残すため同梱しています。
