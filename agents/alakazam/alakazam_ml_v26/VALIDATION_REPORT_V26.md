## 制約

- teacher-forced 再生は、変更後の後続盤面をシミュレートしない。
- ローカルの `marnies_grimmsnarl_ex_v7` はラダーのオーロンゲより弱い（こちらが 70% 勝つ一方、
  ラダーでは 8/27 = 29.6% しか勝てない）。オーロンゲ対面の真の改善幅は測れていない。
- ネイティブ対戦 API は乱数シードを完全固定できない。
- ラダーのレート単体では版の優劣を判定できない。次の提出でも、対面別勝率と
  `boardout` / `deckout` の件数で評価する。
