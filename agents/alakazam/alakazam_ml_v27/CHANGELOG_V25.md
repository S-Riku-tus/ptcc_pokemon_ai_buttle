# v25変更履歴

## 旧v25からの撤回

- 気絶後にノココッチ・フェザンディピティより未完成のケーシィ／ユンゲラー／フーディンを広く昇格する規則を削除。
- ミラーでフェザンディピティを「直ちに特性を使える場合だけ」に限定する規則を削除。
- 旧v25を継ぎ足さず、`alakazam_ml_v24`をそのままコピーした状態から再実装。

## v24からの限定変更

1. `Run Away Draw`の山札収支を、固定3枚消費から解決後の公開カード収支へ変更。
   - 最大3枚ドロー
   - ノココッチ本体と進化元ノコッチを最低2枚返却
   - 公開されているエネルギー・どうぐも返却枚数へ加算
   - 「唯一の盤面なら使わない」という即敗北防止は維持
2. バトル場で即座に取れるサイド枚数より少ないベンチ対象は、役割ボーナスだけではボス対象に昇格させない。
3. アーチャルドンexへの確定ルートを維持。
   - 即KO可能ならエースバーンへ逃げない
   - 明確な2発圏なら、勝利確定以外のボスを行動段階で抑止
   - エースバーンを除外した後に別の1枚取りへボスを使う代替経路も抑止
4. 生きているユキメノコがある盤面では、マシマシラの追加役割ボーナスを外す。

## 変更していないもの

- 60枚のデッキ
- LightGBM行動ランカーと、その限定されたライブ適用範囲
- Yushin Ito 1000戦で学習した標的ランカー
- v24の終端勝利、ミストエネルギー、ハンマー、フェザンディピティ、退避、バックアップ構築ロジック
