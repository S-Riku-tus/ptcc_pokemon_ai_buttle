# v27 変更一覧

親は `alakazam_ml_v26`（submission 55045289、公開48戦28勝20敗）。デッキ60枚、
行動ランカー、標的ランカーは変更していません。

## 1. サポートActiveからの攻撃変換

`_support_pivot_attack_route()` を追加し、次を一つの仮想ルートとして評価します。

1. Activeがキチキギスex・ノコッチ・シェイミ・ケーシィ・ユンゲラーのいずれか。
2. 必要なら手札からエネルギーを1枚付ける。
3. 逃げる。
4. 準備済みのベンチフーディンをActiveへ出す。
5. 現在の相手Activeを攻撃する。

エンリッチエネルギーなら、手札から1枚減って4枚引くため、攻撃時手札を `+3` として
「ちょうねんりき」の打点とKOを再計算します。v26ではキチキギス専用分岐が先にreturnし、
汎用ピボット評価まで届かなかったため、v27ではこのルートを先に評価します。

## 2. 主戦力と進化前の標的優先

`EVOLVES_FROM_INDEX` を使い、カードIDの個別表だけに依存せず、主戦力の価値を最大2段階前まで
伝播します。同じ1サイドKOなら主戦力本体、1進化、たね、使い捨てbodyの順になります。

主戦力の終点は ex・メガ・2進化、または高打点/可変打点を持つ1進化、戦略特性を持つ1進化に限定します。
30打点だけの付随的な1進化ラインなどには新ボーナスを付けません。

サイドを取り切るActive ex、より多くサイドを取れるKO、効果ロック解除は従来どおり外側のゲートで優先します。

## 3. 標的別の手札予算

選択済みKOルートに必要な攻撃時手札を `ceil(標的の残りHP / 20)` として扱います。
その枚数に到達し、ルートが追加ドローを要求していなければ、ノココッチの特性と
ドロー目的だけのエンリッチを使いません。

例: 残りHP 200なら必要手札は10枚です。10枚以上ですでに確定KOなら特性を保存し、
9枚で特性がKOを作るなら使います。ベンチ標的へボスを使う場合は、ボス使用後の手札枚数で判定します。
