# alakazam_ml_v27

v26 の60枚と学習モデルを維持し、ユーザー指定の3つの判断ミスを決定論ロジックで修正した候補版です。

- キチキギスexなどがActiveに取り残されたとき、手札のエンリッチエネルギー等を付け、
  逃げてベンチのフーディンを出し、そのターンに攻撃する一連のルートを評価します。
- 相手の主戦力とその進化前を進化グラフから認識し、同じサイド帯なら
  `主戦力 > 中間進化 > たね > 使い捨てbody` の順で狙います。
- 選んだ標的を倒す手札枚数 `ceil(残りHP / 20)` に到達したら、そのKOに不要な
  ノココッチの「にげあしドロー」やエンリッチの追加ドローを止めます。

ただし、終端勝利と高サイドKOは常に優先し、主戦力狙いだけでサイドレースを落とさないようにしています。
弱い進化先をすべて主戦力扱いすることも避け、ex・メガ・2進化・高打点1進化・戦略特性に限定しました。

エージェント内テストは160件成功、静的検証は60枚・22種・警告0です。v26実ラダー48戦の
teacher-forced再生では2,958判断中68件（2.30%）だけが変わりました。汎用5対面は472/500で
同seedのv26の471/500と同等でした。一方、v26との600戦ミラーは287/600（47.8%）で、
50%との差は明確ではないものの、ローカルでの純粋な強化はまだ実証できていません。

詳細は `CHANGELOG_V27.md`、`ANALYSIS_V27.md`、`VALIDATION_REPORT_V27.md` を参照してください。
