# v27 設計根拠

## 実装上の重要点

### ピボット

エネルギー付与単体を評価すると、手札増加・付与先・逃げる価値・攻撃価値が別々の低いスコアに分かれます。
v27は最終攻撃までを一つのルートにし、実際のKO/勝利スコアを入口の付与と逃げる選択へ戻します。
これにより「エンリッチを引くために使う」のではなく、「フーディン攻撃へ変換できるから使う」判断になります。

### 標的

単純なHP最小やex優先では、次のターンに主戦力へ進化するたねを見逃します。一方、全進化ラインへ
大きな固定点を与えると過剰にボスを使います。そこで主戦力終点だけをカードデータから判定し、
その価値を進化前へ逆伝播させます。終端勝利・サイド枚数・現在Activeの確定KOは別ゲートとして残します。

### 手札

追加ドローの停止条件は固定上限ではなく、選択済み標的の残りHPと予定行動後の手札で決まります。
これによりHP 200では10枚で止まり、HP 260なら13枚まで増やします。ノココッチを場に残すこと自体が、
相手の手札リセット後に再び引ける回復手段になります。

## teacher-forced差分の読み方

v26実ラダー48戦、2,958判断の再生で意味上の変更は68件（2.30%）、24試合でした。
代表的な変化はエンリッチ選択38件、逃げる選択3件、v26がノココッチ進化/特性を選んだ局面からの変更18件、
ボス選択5件です。勝ち試合18・負け試合6に変更が出ました。

これは変更が狙った局面に実際に発火する確認であり、記録されたv26手を教師にした再生なので、
v27の勝率改善を証明するものではありません。変更後の盤面推移もteacher-forcedでは再現されません。
