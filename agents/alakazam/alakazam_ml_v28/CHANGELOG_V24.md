# v24 変更一覧

## 標的とボス

- `boss_prize_upgrade_targets`を経路ベースへ変更
- 場がKO不能でも、ボス消費後の手札でベンチex/Mega exを同ターンKOできれば強制候補化
- 同一カードの場個体と傷ついたベンチ個体を別のHP状態として評価
- 場の1サイド高役割ポケモンに対するv23の一律例外を廃止し、確定複数サイドKOを優先
- ゲーム勝利になる場のKOは従来どおり最優先
- ボス解決後は新しい標的ランカーで候補を再順位付け

## オーロンゲ対面

- 場のオーロンゲexが現在火力の2発圏内なら、マシマシラから別の1サイド標的へ乗り換える経路も含めて序盤ボスを抑止
- 2発圏外、攻撃無効、またはマシマシラを倒す必要がある盤面では従来のフォールバックを維持
- ユキメノコ等の重要な1サイドエンジンに対する一般的なボス規則は変更なし

## ノココッチ

- 山札1～2枚かつ同ターンKOになる場のノココッチ特性を、デッキ保護ゲートの限定例外化
- 山札0枚では特性を許可しない
- 3エネ目の付与で逃げるコストを満たし、ベンチフーディンが同ターンKOできる場合のみ、付与→逃げるを許可
- 通常の手札増加、山札保護、唯一の場ポケモン保護は維持

## 学習

- Yushin Ito 1000ログからカードID非依存のpairwise target rankerを再学習
- 2217 preference pairs、16特徴
- 学習値は決定規則内の±800タイブレークに限定
