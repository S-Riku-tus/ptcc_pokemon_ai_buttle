# alakazam_ml_v29

v29は、上位フーディン5チームの対戦ログからMAIN行動を学習した、v28ベースの教師模倣エージェントです。デッキ60枚とv28の決定論的方策は維持し、その上に順位重み付きLambdaRankモデルを追加しています。

## 方策

- 対象: 同一デッキの上位361試合、MAIN 18,336盤面、192,179候補
- 教師重み: `1 / sqrt(leaderboard rank)`
- 特徴量: 盤面、手札・山札、順序付きベンチ、合法手集合、v28スコア、旧ランカースコアの計422個
- 重複カード: 同じカード・技・対象状態なら同一の正解として扱う
- 適用範囲: 1枚を選ぶMAIN contextのみ
- 閾値: 0.20。低信頼、入れ子選択、複数選択、時間不足時はv28へ戻す

即時勝利、現在のKO、Bossの確定ルート、攻撃可能なフーディン、2体以下の盤面でのノココッチ維持には安全制約を置いています。

## 検証の読み方
