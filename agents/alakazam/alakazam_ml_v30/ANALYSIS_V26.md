# v26 分析・設計

## 結論

v25 はラダー 57 戦 36勝21敗（63.2%）で、v24 の 2 本（30勝30敗 / 38勝36敗、合計 68勝66敗 = 50.7%）から明確に前進しました。ノココッチ循環の修正は効いており、山札切れ負けは v24 の各 5 件から 2 件へ減っています。

そのうえで v25 の 21 敗を全数分解すると、敗因は「戦術の巧拙」ではなく**盤面ポケモン数がゼロになる、あるいは 1 体まで落ちる**という単純な事故に偏っていました。v26 はこの 1 クラスと、v24+v25 を通じて唯一構造的に負け越しているオーロンゲ対面だけを対象にしています。

## 敗因1: 盤面body切れ（v25の21敗中7敗）

全 MAIN 判断を走査し、「自分の盤面ポケモンが 1 体以下になったターン」を抽出しました。

| 集計 | v25 | v24再提出 | v24・1本目 |
|---|---:|---:|---:|
| 1体以下でターンを終えた試合 | 8（うち7敗） | 14（うち8敗） | 5（うち2敗） |
| そのとき盤面を増やす手があった試合 | 5（**5敗**） | 10（うち6敗） | 2（うち1敗） |
| ノココッチ特性で2体→1体にした回数 | 3 | 7 | 4 |

v25 では「1 体以下で、かつ盤面を増やす合法手が残っていた」5 試合が**すべて負け**です。21 敗の 24%、`boardout` 2 件と極端な早期敗北はすべてこのクラスに含まれます。

見送られていた手の内訳（3 本合計）: シェイミ 18 回、ヒカリ 24 回、ノコッチ 4 回、ポフィン 3 回、フェザンディピティ ex 4 回。

### 代表例

- **88471860（3ターン敗北）**: 場はフェザンディピティ ex のみ、ベンチ 0。手札にヒカリ（たねポケモン+1進化+2進化をサーチ）とヒルダ（進化ポケモン+エネルギーをサーチ）。v25 は**ヒルダ**を選び、ユンゲラーと基本超エネルギーを持ってきました。場にケーシィがいないのでユンゲラーの置き場がなく、盤面は 0 のままターン終了。次のターンに気絶して敗北。
- **88455088（turn 11）**: 盤面 1 体。オプションに `PLAY:シェイミ` があったにもかかわらず、ヒルダ → 聖なる灰 → END の順に選び、シェイミを一度も出しませんでした。`boardout` で敗北。
- **88497435（turn 5）**: 場ノコッチ→ノココッチに進化させてから Run Away Draw。ベンチのフーディンを昇格させた結果ベンチ 0。手札にシェイミがあったが出さず、次ターンに気絶して `boardout`。

### 原因

1. `_score_play_poke` のシェイミは `17000 if (n == 0 and self._opp_threatens_bench()) else -1`。「ベンチ被弾対面でなければ絶対に出さない」ため、盤面が 1 体でも出しません。v25 のラダー 57 戦でシェイミが場に出たのは 5 試合だけです。
2. ヒルダ `12500` > ヒカリ `12000`（ともに `_need_pieces()` 時）。進化先が場にない状況でも順序が入れ替わりません。
3. Run Away Draw の安全弁は `_board_body_count() <= 1`、つまり「ノココッチが最後の 1 体のときだけ」禁止でした。2 体 → 1 体は素通りします。

## 敗因2: オーロンゲ対面でユキメノコを一度も処理しない

オーロンゲ側の構成は Marnie's Grimmsnarl ex 3 + **ユキメノコ 2** + マシマシラ 4 です。

- Shadow Bullet: バトル場 180 + **ベンチ 1 体に 30**
- ユキメノコ「フリージングシュラウド」: ポケモンチェックのたびに、**特性を持つすべてのポケモン**にダメカン 1 個

こちらの盤面はフーディン・ユンゲラー・ノココッチ・フェザンディピティ ex・シェイミがすべて特性持ちです。ユキメノコ 2 体で**毎ターン全 body に 20 ダメージ**が乗ります。実際 88469739 では、攻撃を受けていないベンチのユンゲラー 2 体が turn 5 の 80/80 から turn 7 に 10/80 まで削られていました。

にもかかわらず、**3 試合を通じてボスの指令は 0 回**です。手札に 2 枚あるターンが複数ありました。

`_boss_target_score` を実際に再実行して原因を特定しました（88469739 turn 9、step 113）:

```
target=ユキメノコ dmg_after_spend=320 hp=90       → 同ターンKO可能
active=マニィのオーロンゲ(Morgrem) hp=100 best=340 → active_ko=True
target_prizes=1  active_prizes=1                  → サイドは同数
target_role=4600 active_role=4100                 → role_upgrade は +1500 必要 → 不成立
target_value=7545 active_value=8190               → 7545 < 8190+700
→ boss_active_ko_dominance_blocks → -1
```

つまり「バトル場も同じ 1 枚取りで倒せるなら、わざわざベンチを釣らない」という v11 由来の支配則が、**エンジンカードの除去**という別種の価値を評価できていません。上位の Yushin Ito は 1000 戦でユキメノコを **346 回**釣っています。こちらは 0 回です。

同時に、`_opp_threatens_bench()` は「相手**バトル場**が今すぐ払えるベンチ打点を持つ」ことを要求します。オーロンゲ ex がバトル場に立ってエネルギーが乗った時点で初めて真になるため、シェイミの設置は常に手遅れでした。ベンチ 30 はユンゲラー 80HP を 3 発で落としますが、判定は 2 発分しか見ていません。

## v26 の変更

実ログで再現し、かつ「やらなかったこと」が負けに直結している 4 点に限定しました。

### 1. 盤面body下限（board-count floor）

盤面が 1 体以下のとき、body を増やす手を非終端行動の最上位に置きます。優先順は、ポフィン（2 体）62000 > テレパシックエネルギー（超ポケモンに貼れば 2 体）61500 > ケーシィ/ノコッチ 61000 > ポケパッド 60800 > フェザンディピティ ex 60500 > シェイミ 60000。

このゲートは**致死維持ゲートより前**に置いています。88457742 では、致死維持ゲートが `PLAY:ノコッチ` を 10 点まで下げて 2 サイド分の Powerful Hand を守り、唯一のポケモンで殴って返しで `boardout` しました。1 体で立っていること自体が負けなので、そちらを優先します。ゲーム勝利になる攻撃（`_terminal_win_attack_offered`）だけは従来どおり最優先のままです。

END も、盤面 1 体以下で body を増やす手が残っているときは選べません。

### 2. Run Away Draw の下限を 2 体へ

`_board_body_count() <= 2` かつ「この手番で body を戻せる手（たねポケモン/ポフィン）が提示されていない」場合、循環を拒否します。ただし次は従来どおり許可します。

- 勝利になるピボット
- 同ターンKOルートに組み込まれた循環（`_chosen_route_action_score("dudun")`）
- 低山札ピボットルート

実ログで問題だったのは「純粋なドロー」と「攻撃者を昇格させるだけの入れ替え」であり、KO に直結する循環ではありませんでした。

### 3. 進化先が場にないときはヒルダよりヒカリ

場にケーシィ・ユンゲラー・ノコッチが 1 体もいない場合、ヒルダは 2000（サーチしても置き場がない）、ヒカリは 19000（たねポケモンが手に入る）に変わります。それ以外は v25 のままです。

### 4. オーロンゲ対面

- `_opp_threatens_bench()` を拡張: 相手盤面のポケモンとその**進化先**まで見てベンチ打点を判定し、判定窓を 2 発から 3 発（ユキメノコがいれば 4 発）に広げる。ただし**露出している非ルールボックスのベンチが 2 体以上**あり、かつ**自盤面が 3 体以上**（=ライン用のベンチ枠を潰さない）ときだけ真にする。
- `_checkup_counter_engine_upgrade()` を追加: ポケモンチェックでダメカンをばらまく特性（カードテキストから自動抽出。現環境ではユキメノコのみ）を持つ相手を、**サイドが同数以上**で、**こちらの特性持ちが 2 体以上**課税されているときに限り `role_upgrade` として扱い、active_ko 支配則を通します。

## 不採用

- デッキ 60 枚、行動ランカー、標的ランカーの変更: 今回の敗因はいずれもルート計算の欠落で、学習不足ではありません。
- シェイミの無条件設置: 拡張版（露出 1 体でも設置）は marnies_grimmsnarl_ex_v7 との 1,800 戦で v25 と同値（70.0% 対 70.2%）でした。条件を絞った版だけが +1.9pp を出したため、絞った側を採用しています。
- ユキメノコ対面でユンゲラーへ進化させない（ケーシィ 50HP は特性を持たないためチェック無傷）という案: 実ログでの裏付けがなく、攻撃ラインを直接壊すため見送りました。

## 検証の限界

- teacher-forced 再生は、変更後の後続盤面を再現しません。
- ローカルの `marnies_grimmsnarl_ex_v7` は同じ 60 枚を使いますが、ラダーのオーロンゲより明確に弱く（こちらが 70% 勝つ一方、ラダーでは 29.6% しか勝てない）、ユキメノコ課税の再現度は不明です。局所指標としてしか扱えません。
- ラダーのレート単体では版の優劣を判定できません（同一エージェントで 842.8 と 804.0 の実績あり）。次の提出でも、対面別勝率と `boardout` 件数で評価します。
