# v28 設計根拠

## 課題1: ノコッチからケーシィを前に出す

v27ではノコッチの交代技が700点、通常のターン終了が0点でした。ベンチに攻撃可能なフーディンがいる場合はさらに5000点でした。このため、交代先選択側ではノコッチを最良の盾役と評価していても、主行動側では交代技が常にターン終了を上回る局面がありました。

修正はカードIDだけの例外ではなく、ターン終了後の盤面価値比較にしました。交代先評価は、ノコッチ、ノココッチ、条件を満たすキチキギスex、その他の盾役、フーディン進化ラインの順に「前へ置いてよい」度合いを持ちます。交代技は、その最大値が現在のバトル場を厳密に上回る場合だけ使います。

このため、ノコッチ前・ケーシィ後ろでは終了、ケーシィ前・ノコッチ後ろではテレポートになります。準備済みフーディンも、相手ターンを迎える直前にはノコッチの後ろに保持します。

## 課題2: 環境中核の標的順位

2026-07-28 23:05 JSTに公開リーダーボードを再取得しました。上位5チームはDominic Peel、flg、LiamK、Iliamna、JZで、代表提出から各25試合を取得しました。

直近125戦にはジュラルドンが含まれなかったため、ここだけを根拠に優先度を下げてはいません。既存の上位フーディン公開ログではMajkel1337が3回、Yushin Itoが1回ジュラルドンをBoss標的にしています。また上位フーディン8チームの793戦集計では、ブリジュラス／エースバーン対面は27戦ありました。

カードデータ上、ジュラルドンはブリジュラスexへ進化します。ブリジュラスexは進化時にトラッシュの基本鋼エネルギーを2枚まで鋼ポケモンへ付けます。したがってジュラルドンの除去は、1サイドを取るだけでなく、次のアタッカーとエネルギー加速を同時に消す行動です。v27の汎用進化ライン値2300では同じ1サイドのエースバーン3200を下回るため、v28ではジュラルドンを4700へ上げ、同ターンKO可能なら明確な役割アップグレードとしました。

## 制約

環境ボーナスは到達可能性を作りません。Bossを使った後に倒せない標的、現在のバトル場で勝利できる標的、より多くサイドを取れる標的には、従来の到達可能性・終端勝利・サイド支配則が先に適用されます。
