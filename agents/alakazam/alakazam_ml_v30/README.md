1. 上位ログと同じ観測・選択肢なら、`teacher_memory.bin`から教師の意味的行動を復元する
2. 未見の単一選択MAINなら、648特徴のv30 LambdaRankで全合法手を順位付けする

4. 対象外context、低信頼、時間不足、例外時は凍結したv29へ戻る
