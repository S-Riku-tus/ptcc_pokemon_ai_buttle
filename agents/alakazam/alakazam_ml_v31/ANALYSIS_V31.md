# v31 分析

## 評価原則

成功判定には、教師エピソードをID順に70/10/20へ分けた未学習テストだけを使用した。同一試合の盤面を学習とテストへ跨がせていない。カード・攻撃・対象が意味的に同じ重複候補は1候補へ統合した。

## 教師の整合性

主教師をMajkel1337の現行提出54662660へ固定した。Rmy単独は73.38%、MajkelとRmyの混合は69.61%まで低下した。Majkel直前提出54618168を重み0.25以上で加える実験もすべて悪化した。このため、最終モデルには現行Majkelだけを使用した。

## 採用した改善

v30の648特徴へ、合法手の順序・生インデックス・同種候補の先行数9特徴を追加した。単体の改善は小さかったが、カテゴリIDを使う大葉モデルとIDを数値扱いするモデルで誤りに差が出た。検証で両者を1.0:1.3に混ぜると、テストTop-1は76.31%になった。

## 不採用実験

- 行動種→同一行動内候補の階層分類
- listwise位置分類
- 通常・OOFペア比較
- 長い行動履歴、相手トラッシュ、手札順序、カードserial
- 盤面ハッシュ交差特徴
- MLP再順位付け
- SVD近傍検索
- CatBoost QuerySoftMax
- Rmy・旧Majkel・Yushinとの教師混合
- 3モデルのスタッキング

いずれも凍結テストで76.31%を上回らなかった。

## 90%監査

単一モデルTop-3は95.31%だが、6種類のモデルについて「どれか1つがTop-1正解」の理想オラクルでも82.70%だった。同一試合内の判断を学習とテストへ混在させる診断でも82.99%だった。遷移ラベルは20試合1,607判断で次ステップ行動の合法率100%を確認しており、1ステップずれではない。

したがって、現時点の76.31%を90%と報告することはできない。90%へ進むには、同一現行提出の追加ログ、教師コードまたは教師のスコア、あるいは試合内の完全な方策状態を表現できる新データが必要である。
