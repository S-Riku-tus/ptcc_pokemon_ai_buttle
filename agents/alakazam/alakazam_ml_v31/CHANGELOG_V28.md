# v28 変更一覧

親は `alakazam_ml_v27` です。デッキ60枚、`ranker_model.json`、`target_ranker_model.json` は変更していません。

## 1. ターン終了時の自分のバトル場

`_best_end_turn_switch_improvement()` を追加し、ターンを終了する交代技の主行動評価と、実際の交代先選択を同じ `_score_end_turn_switch_choice()` で判定するようにしました。

- 現在のバトル場より安全な盾役がベンチにいる: 交代技を使用可能。
- 同価値以下の候補しかいない: 交代技を `-1` とし、`END` を選ぶ。
- ノコッチが前、ケーシィ／ユンゲラー／フーディンが後ろ: 進化・攻撃ラインを前に出さない。
- ケーシィが前、ノコッチが後ろ: テレポートでノコッチを前に出し、進化ラインを守る。

これにより「技が使えるから使う」評価と、交代先で盾役を選ぶ評価の不一致を解消しました。

## 2. 主要デッキの中核標的

2026-07-28 23:05 JSTの上位20スナップショットと、上位5提出から各25試合、合計125試合を確認しました。上位AIのBoss標的84件では、マシマシラ30件、ユキメノコ19件、メガガルーラex 4/4候補、キチキギスex 3/4候補が選ばれています。

`BOSS_KEY_ROLE_BONUS`を更新し、継続エンジン、壁、主要進化前を同サイド帯で優先します。特にジュラルドンは、ブリジュラスexへの進化と進化時の基本鋼エネルギー2枚加速を同時に止めるため、エースバーンより高い役割値にしました。

この値は終端勝利や上位サイドKOを上書きしません。Boss、キチキギスexのベンチ狙撃、一般標的順位が同じ役割評価を共有します。
