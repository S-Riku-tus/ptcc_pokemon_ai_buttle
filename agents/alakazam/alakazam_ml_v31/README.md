# alakazam_ml_v31

v31は、同一方策の整合性を優先してMajkel1337の現行提出1,000試合を主教師に固定したフーディンデッキ用エージェントです。デッキ60枚とv29の安全フォールバックは変更していません。

未学習の単一選択MAIN盤面では、657特徴を使う2つのLambdaRankモデルを実行します。

- 大葉・カテゴリIDモデル
- 数値IDモデル
- 各候補集合内でスコアを標準化し、検証で選んだ1.0:1.3で合成
- 既知ログは`teacher_memory.bin`で意味的一致100%
- 非対応・危険・時間不足・違法候補はv29または決定的方策へ戻す

厳密な時系列エピソード分離テストのTop-1意味的一致率は76.31%です。v30の記録73.95%から+2.36ポイント（相対+3.19%）改善しました。同じv31評価盤面上の単体基準75.02%との比較では+1.29ポイントです。要求された90%には未達です。単一モデルのTop-3は95.31%、6モデルの理想オラクルでも82.70%であり、現データと評価したモデル群を単純に混合するだけでは90%へ届きません。
