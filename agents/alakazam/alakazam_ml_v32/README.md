# alakazam_ml_v32

v32は、実戦で最高レート1,050・900台安定を記録したv31を完全に保存したまま、その安全ロジックと既知盤面メモリを継承し、未学習盤面の順位モデルだけを更新したチャレンジャーです。

提出用ランタイムは外部MLライブラリを使いません。Yushin Itoの同一60枚フーディンデッキ1,000試合（有効999系列、49,590 MAIN判断）から学習した657特徴の大葉LambdaRankを、JSON木として標準ライブラリだけで推論します。古い系列も最低25%残しつつ新しい系列を二乗カーブで重視し、検証で効果がなかった数値IDモデルは提出本体から除外しました。

厳密な時系列分離テストのTop-1意味的一致率は78.71%です。同一seedの均等学習77.22%から+1.49ポイント改善しました。v31の公表値76.31%より数値上は+2.40ポイントですが、v31はMajkel、v32はYushinの別ホールドアウトなので、同一テスト上の純粋な改善量ではありません。

両方の最終学習から除外した同じRmy test 6,045判断では、v31最終木58.43%に対しv32は61.67%で+3.24ポイントでした。ただしRmyは過去の研究で確認済みのため、主ホールドアウトではなく補助比較として扱います。

研究用6モデルではTop-1 80.12%、recency木と低重みMajkel補助木を加えた8モデルのいずれかが正解するオラクルは91.68%でした。これは「候補モデル群には90%超の正解が含まれる」ことを示しますが、追加2モデルはvalidationで重み0となり、実際に正しいモデルを選ぶ仕組みは80.12%に留まるため、目標90%は未達です。PyTorchモデルは提出用エージェントに含めていません。

v31は実戦チャンピオンのまま保持し、v32は対戦投入前のチャレンジャーとして扱います。詳細は`ANALYSIS_V32.md`と`VALIDATION_REPORT_V32.md`を参照してください。
