# v32 分析

## 出発点

v31はユーザー実戦で最高レート1,050へ到達し、その後900台で安定した最初の版です。そのためv32では、デッキ・決定論フォールバック・即時リーサル等の安全ガード・既知Majkel盤面メモリを変更せず、未学習MAIN盤面の順位モデルだけを改善対象にしました。

## 新しい主教師

既存インデックスを再監査すると、v31作成時点では最終学習に使われていなかったYushin Itoの提出54773249が見つかりました。2026-07-26時点3位、同一60枚デッキ、1,000完走試合です。999の一意系列から49,590判断・443,714候補行を抽出し、episode ID順70/10/20で分離しました。

## 検証したモデル

木モデル6種、DeepSets複数seed、集合Attention、履歴拡張、recency weighting、盤面・スコアstacking、蒸留、候補コンセンサス、局面別weightを検証しました。さらに意味シグネチャ記憶、行動種prior、順位・確率融合、2位Majkelログの低重み補助学習、Majkelで学習してYushin前半で校正する外部selectorも検証しました。weightやstackerはvalidationだけで決め、testは最終確認にだけ使用しています。

提出可能な標準ライブラリ構成では、時系列重み付き大葉LambdaRankがvalidation 77.97%、test 78.71%で最高でした。同一seed 1091の均等学習はvalidation 77.13%、test 77.22%であり、recency重みの効果を分離して再現しています。重みは古い系列を最低0.25残し、episode順の位置を二乗して1.0まで増やします。数値ID木との混合は改善せず除外しました。最終JSON木は全999系列・49,590判断、692 iterationで再学習しています。

教師差を取り除く補助比較として、両方の最終fitから除外した同じRmy test 6,045判断へ最終JSON木を適用しました。v31は58.43%、v32は61.67%で、v32が+3.24ポイントでした。ただしRmyは以前の実験で一度確認しているため、完全に未閲覧のモデル選択用holdoutとはみなしません。

研究用では6モデル合成がvalidation 80.21%、test 80.12%でした。recency木とMajkel 2.5%補助木を加えた8モデルのtest oracleは91.68%です。しかしoracleは正解を見てからモデルを選ぶ上限であり、実際のTop-1ではありません。追加2モデルはvalidationで重み0でした。決定単位gatingは79.87%、階層モデルは77.33%、局面切替は79.96%以下でした。意味シグネチャ記憶、行動prior、順位融合、Majkel外部selectorも固定blendを超えませんでした。

## 判断

v32は未達目標を達成した版ではなく、現時点で安全に提出できる最良のチャレンジャーです。研究結果から次のボトルネックは候補生成ではなく「同じ盤面で、どの教師・どのモデルの判断を信用するか」の選択です。実戦価値が確定しているv31は上書きせず、championとして残します。
