# v33 変更点

- 旧v33（OOF selector版）を削除し、v32を複製して作り直し
- v32の検証100試合・テスト200試合を1判断単位で凍結し、v32との直接比較を可能化
- Yushin Ito提出54773249のログを再点検し、未使用だった289試合を回収（1,288試合／1,284有効／67,340 MAIN判断）
- 追加289試合のシート正当性をリプレイの`TeamNames`で個別検証
- 分割境界をepisode ID固定に変更し、追加分が学習にだけ入ることを保証
- LambdaRankのラベルをターン順序gradedへ変更（選択7／次の判断で選択3／同ターン後半で選択1／打たれない0）
- ターン内履歴8特徴を抽出とランタイムの両方に実装（重複候補を1回だけ数える定義で統一）
- ランタイムのターン内履歴が学習コーパスと完全一致することを12試合6,513候補行で検証
- ランタイムを最大3モデルの重み付きblendに一般化（各モデルは候補集合内でz標準化）
- blend採用ゲート（validation +0.20ポイント）を追加し、+0.10の第2モデルを自動不採用
- 教師ID条件付きマルチ教師学習を検証し、-3.53ポイントで不採用
- 表現上限・過学習・盤面再出現率・ターン内順序の4診断を追加
- 同一教師データ量のスケーリング曲線を測定（1桁あたり+8.47ポイント）
- 順序を問わない一致率（turn-set）を評価指標に追加
- v33専用環境変数`ALAKAZAM_ML_V33_*`を追加（v32・v31名は後方互換）
- v33回帰テストを追加し、184テスト成功

凍結ホールドアウトのTop-1はv32の78.71%から79.51%へ、Top-2は91.89%から93.11%、Top-3は96.25%から97.12%へ改善しました。目標90%は未達です。
