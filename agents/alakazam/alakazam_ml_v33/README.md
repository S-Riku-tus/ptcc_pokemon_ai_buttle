# alakazam_ml_v33

v33はフーディン系列の現champion。**実ラダー最終レート916.9**（submission 55129390、public 42-29）で、v31の881.2・v32の871.9を上回る系列最高です。

デッキ60枚、v29安全フォールバック、Majkel盤面メモリ、リーサル保護などの安全ロジックはv31から一切変更していません。変えたのは、未知のMAIN盤面で「上位チームと同じ手を選ぶ」順位モデルだけです。

## v33で何が変わったか

**v32と同じ土俵で測れるようにした。** v31はMajkel、v32はYushinのホールドアウトで測っていたため、76.31%と78.71%は比較できませんでした。v33はv32の検証100試合・テスト200試合を1判断単位で凍結し、group長・ラベル・657特徴の全セル一致を確認したうえで学習側だけを拡張しています。

**ターン順序をLambdaRankの関係度にした。** 二値ラベルは「2手後に必ず打つカード」と「そのターン打たないカード」を同じ0で罰します。v33は選択手7、次の判断で選ぶ手3、同ターン後半で選ぶ手1、打たない手0の4段階にしました。評価は従来どおり厳密な二値Top-1のままです。

**同一提出の未使用ログ289試合を回収した。** Yushin Ito提出54773249について、v32が使った2026-07-26の1,000試合に加え、2026-07-17に180試合、2026-07-24に109試合が残っていました。合計1,288試合・67,340 MAIN判断です。すべて凍結境界より古いので学習にだけ入ります。

この2つは単独ではほとんど効かず（データ追加のみ-0.59、graded単独+0.21）、併用して+1.40ポイントになります。

## 90%が遠い理由（測定済み）

- 1判断内で区別できない候補行は0件。657特徴の理論上限は100%で、特徴表現は原因ではない
- 学習Top-1 96.9%に対しホールドアウト78.1%。容量ではなく汎化が律速
- 学習35,704判断の盤面は35,704通りすべて一意。記憶や近傍法の余地はない
- v32の誤りの59.98%は「教師も同じターン内で打つ手」の順序ずれ。順序を問わない一致率はすでに92.30%
- 同一教師のデータ量とTop-1は対数線形で1桁あたり+8.47ポイント。90%には同一提出のログが約16,400試合必要（手元は1,288試合）

つまり90%未達は探索不足ではなく、同一提出ログの桁違いの追加、教師スコアそのものの観測、または評価指標の変更のいずれかが必要です。

ターン内履歴の実装とパリティ検証はランタイムに残してあります（12試合6,513候補行で学習コーパスと完全一致）。将来モデルが採用すれば`uses_turn_features`フラグだけで有効になります。
