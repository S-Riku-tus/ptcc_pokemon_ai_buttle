# alakazam_ml_v34

v34は、実戦championのv31とオフラインchallengerのv32を保存したまま、上位フーディンログの時系列未学習盤面に対する行動模倣を改善したchallengerです。

主な変更は、現在盤面だけでなく、その試合で直前に選んだ4判断、行動種類の累積回数、同一ターン内の判断位置、最後の攻撃・進化・給エネ・トレーナー使用からの経過ターンを、候補ランキングへ入力したことです。

## オフライン結果

Yushin Itoの同一60枚フーディンログ1,000試合から、999系列・49,590判断・443,714意味候補を再構成しました。episode ID順で70/10/20へ分け、最後の8,848判断は学習とearly stoppingに使用していません。

| 構成 | Validation Top-1 | Test Top-1 | Test Top-2 |
|---|---:|---:|---:|
| v32提出モデル | 77.97% | 78.71% | — |
| v32研究6モデル | 80.21% | 80.12% | — |
| **v34 sequence-state LambdaRank** | **80.81%** | **80.63%** | **93.30%** |
| v34 OOF residual selector | 80.94% | 81.09% | 93.61% |
| v34 leak-free GRU selector | 81.38% | 81.01% | 93.30% |

提出ランタイムには、validationとtestの双方で安定し、標準ライブラリだけで再現できる単一のv34 sequence-state LambdaRankを採用しています。研究selectorは小幅改善に留まり、PyTorch依存も必要になるため同梱していません。

目標のTop-1 90%は未達です。Top-2包含率は93.30%まで到達しているため、次の中心課題は候補生成ではなく、上位2候補を正しく並べ替えることです。

## 安全性

- デッキ60枚とv31/v32の決定論フォールバックを維持
- Majkel既知盤面メモリを維持
- v29 residual rankerを維持
- 即時リーサル・違法手・低残り時間・未対応選択の安全ゲートを維持
- v34モデルは標準ライブラリだけで推論
- 学習時とランタイムの674特徴を1,251候補で照合し、最大誤差0
- LightGBMと蒸留JSONの512候補スコア最大誤差0
- 継承・v34追加テスト181件成功

公式`cg`とローカル対戦ハーネスは今回の添付物に含まれていないため、実エンジン対戦・Kaggle Validation・実レートは未測定です。v31はchampionのまま維持し、v34はchallengerとして評価してください。
