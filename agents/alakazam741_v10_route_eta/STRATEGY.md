# alakazam741_v10_route_eta 戦略概要

alakazam741_v9_top8_core の状態機械・攻撃予約・動的山札管理をそのまま継承し、デッキ（v8/v9と同一の60枚）も変更しない。v10 は「初動事故・後続の誤判定・非ミラーでの無駄な妨害」を減らすため、盤面情報から判定する7つの決定点だけを修正した論理版。対面別のカード名/デッキ名分岐は持たない。

## 維持している中核（v9から不変）

- 攻撃予約：最善の>0ダメージ攻撃を予約し、それを壊さない攻撃前行動のみ許可、攻撃可能な限りENDしない。
- 状態機械：SETUP / PRESSURE / RECOVER / LOCKED / ENDGAME を毎MAINで一つ選ぶ。
- ノココッチ：基本Tierと動的山札管理（実効山札 vs turns_to_win）。最後の1体特性自滅の禁止。
- 退避：攻撃到達のためだけに退避。攻撃可能フーディンから盾へは退避しない。
- 効果無効への0ダメージPowerful Handの禁止。

## v10で修正した7点

1. **完成ルート判定（`_holds_complete_route`）**：到達可能なフーディンが実在する場合のみ完成扱い。ケーシィ＋ユンゲラーだけ・フーディンなし・エネなしは未完成として扱い、リーリエでの手札再構築を止めない。
2. **後続ETA（`_backup_eta` / `_backup_energy_short`）**：ベンチにライン札があるだけでは後続とみなさない。エネルギー込みでETA<=1のときだけ十分な後続。後続エネ不足時はエネルギー確保を追加展開・妨害より優先。
3. **ポケパッド（`_pokepad_target_score`）**：不足している進化段階を取得。ケーシィ不在でのフーディン先行取得を禁止。
4. **ヒカリ/ヒルダ（`_dawn_hilda_scores`）**：盤面の不足で使い分け（ケーシィなし→ヒカリ、進化札/エネ不足→ヒルダ、ライン不足でエネあり→ヒカリ、後続エネなし→ヒルダ）。
5. **クセロシキ**：非ミラーは原則禁止。ミラーかつ攻撃可能な攻撃前妨害としてのみ。LOCKED中・「攻撃せずクセロシキだけでEND」は禁止。現在KO/攻撃を失う場合は攻撃前ゲートで却下。
6. **夜のタンカ**：1ターン1回まで。2回目以降は今ターンのKO成立か次の攻撃役確保に直結する場合のみ。
7. **バトルケージ**：相手スタジアムがあるだけでは張り替えない。実際のベンチ保護が必要なときだけ。現在KO/攻撃の喪失は攻撃前ゲートで防止。
