# CHANGELOG — v11.0.0

## デッキ

- Basic Pokémonを7枚から9枚へ増加
- キチキギスex 1枚、シェイミ1枚を追加
- ポケパッド3→4、ヒカリ3→4
- バトルケージ3→1、夜のタンカ3→2、リーリエの決心1→0
- 基本超エネルギー3→2、エンリッチエネルギー0→1
- 合計60枚を維持

## ロジック

- 生の進化ライン体数ではなく、フーディン札と進化橋を個別消費する`_independent_route_count()`を追加
- 後攻序盤の目標経路数を3本へ設定
- 必要なBasic本体と、進化資源不足を分離し、不要な追加ケーシィ展開を防止
- キチキギスexの条件付き展開、ドロー能力、100ダメージ攻撃、段階的給エネを実装
- シェイミをベンチ攻撃脅威がある場合だけ展開
- シェイミ存在時はバトルケージを重複使用しない
- 改造ハンマーへ、除去後に2エネルギー以上の不足を作る限定テンポ使用を追加
- キチキギスexの能力・攻撃を診断カウンタへ追加
- リーリエ専用の死んだロジックを削除

## 維持

- v10の`backup_eta`
- 攻撃予約と攻撃可能END禁止
- 非ミラークセロシキ禁止
- 夜のタンカ複数回制限
- 最後の1体ノココッチ安全処理
- 0ダメージPowerful Hand禁止
- 最小退避方針
