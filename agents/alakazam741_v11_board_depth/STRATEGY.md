# alakazam741_v11_board_depth 戦略

## 目的

v10のログでは、初回攻撃の速度そのものは十分だった一方、後攻時の盤面が薄く、最初のフーディンが倒された後に攻撃が途切れ、盤面全滅へ進む試合が多かった。v11は攻撃をさらに早める版ではなく、**攻撃を維持したまま盤面の冗長性を増やす版**である。

## デッキ変更

| カード | v10 | v11 |
|---|---:|---:|
| 基本超エネルギー | 3 | 2 |
| エンリッチエネルギー | 0 | 1 |
| キチキギスex | 0 | 1 |
| シェイミ | 0 | 1 |
| ポケパッド | 3 | 4 |
| ヒカリ | 3 | 4 |
| 夜のタンカ | 3 | 2 |
| リーリエの決心 | 1 | 0 |
| バトルケージ | 3 | 1 |

Basic Pokémonは7枚から9枚になる。マリガンと盤面全滅を減らしながら、ケーシィ4枚は維持する。

## 1. 独立したフーディン経路

旧ロジックは、場のケーシィ・ユンゲラー・フーディンの合計が3体なら展開を弱めていた。しかし、3体いても手札・山札にフーディンや進化橋がなければ、実際には後続が1本しかない。

v11では次を別々に消費して経路数を計算する。

- 完成済みフーディン
- ユンゲラーごとのフーディン札
- ケーシィごとのフーディン札と、ユンゲラーまたはふしぎなアメ

PrizeTrackerで山札内枚数を確定できない場合は、存在しない資源を楽観的に数えず、手札で確認できる資源だけを数える。ただし、すでに必要数の進化ライン本体が場にいる場合は、追加ケーシィではなくポケパッド・ヒカリ・ヒルダで不足段階を探す。

## 2. 後攻専用の盤面深度

後攻の序盤は、攻撃可能性を維持できる範囲で3本の「表現可能なフーディン経路」を目標にする。常に盤面5体を強制するルールではない。

- 必要なケーシィ本体が不足している場合だけ追加展開
- 本体は足りるが進化資源が不足している場合は検索を優先
- 後続エネルギーだけが不足している場合はヒルダ・手貼り・夜のタンカを優先
- 現在のPowerful Handが0ダメージまたはKO圏外になる手札消費は禁止

## 3. キチキギスex

キチキギスexは次の役割を持つ。

1. Basic枚数を増やしマリガンを減らす
2. 条件が満たされた時のドロー能力で、被KO後の再建を補助する
3. 3エネルギー到達後は100ダメージの代替攻撃経路になる

ただし2サイドポケモンなので、無条件には出さない。

- 自分のサイドがすでに取られている
- フーディン攻撃経路が不足している
- 後攻序盤で盤面役割が不足している

場合だけ展開候補にする。給エネは、最初のフーディンが攻撃可能で、後続エネルギー不足でもない場合に限定する。0→1→2エネルギーの途中給エネを明示的に許可し、3枚目で攻撃可能になる時は高く評価する。

## 4. シェイミとバトルケージ

シェイミは、相手の場にベンチ攻撃を持つポケモンが存在し、自分のベンチにケーシィ系またはノコッチ系がいる場合だけ展開する。シェイミが場にいる場合、バトルケージは重複防御として使用しない。

バトルケージは1枚だけ残し、シェイミを引けない場合の即時ベンチKO対策として維持する。

## 5. 改造ハンマー

従来の効果無効エネルギー解除は維持する。それ以外では、特殊エネルギーを剥がした後、相手のすべての攻撃が最低2回の追加エネルギー手貼りを必要とする場合だけ使用する。

1エネルギー不足だけでは、相手が次ターンに手貼りして攻撃できるため、テンポ獲得とは扱わない。

## 6. 維持した安全条件

- 攻撃可能時にENDしない
- 非ミラーでクセロシキを使用しない
- 最後の1体のノココッチで特性を使わない
- 攻撃可能なフーディンから盾目的で退避しない
- 効果無効相手への0ダメージPowerful Handを禁止
- 夜のタンカ2回目は、その1枚が直接KOまたは`backup_eta <= 1`を作る場合だけ
- バトルケージなどの手札消費で20ダメージ攻撃を0にしない
- 完成していない手札だけの三段階進化を完成ルート扱いしない

## 評価すべきログ指標

v11の評価ではRatingだけでなく、以下をv10と比較する。

- マリガン発生試合率
- 後攻T1・T2終了時の平均盤面数
- T3時点の独立フーディン経路数
- フーディン攻撃回数／試合
- キチキギスexの能力・攻撃回数
- シェイミを出した対面と、守ったベンチ数
- 盤面全滅負け
- 改造ハンマー使用後、相手が次ターン攻撃した割合
- 攻撃可能なのにENDした回数
- 山札切れ負け
