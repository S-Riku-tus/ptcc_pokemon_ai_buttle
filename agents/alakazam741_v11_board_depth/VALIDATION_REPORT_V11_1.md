# v11.1 修正監査レポート

## 原因

v11.0はハイパーアロマとエンリッチエネルギーを各1枚採用しており、ACE SPEC合計1枚の制限に違反していた。60枚であっても対戦開始前のValidation Episodeで拒否される構成だった。

## 選択した修正

ハイパーアロマを残し、エンリッチエネルギーを基本超エネルギーへ戻した。理由は、v10ログでハイパーアロマが高頻度に使用され、進化ラインの継続に直接寄与していた一方、エンリッチエネルギーはv11で新規導入した未検証要素だったためである。

## コード監査

- `main.py`: エンリッチ定数を削除。エネルギー集合を基本超＋テレパスへ修正。起動時デッキ監査を追加。
- `policy_base.py`: デッキ非依存処理にACE SPEC固有依存はなく、変更不要と判断。構文と既存API経路を再確認。
- `deck.csv`: ID 13をID 5へ置換。60枚を維持。
- テスト: エンリッチ前提の給エネテストを基本超へ置換し、デッキ規則テストを追加。

## 残る制約

実エンジン上のValidation Episodeをこの環境から直接実行できないため、Kaggle側での最終確認は必要。ただし、今回特定したデッキ規則違反は解消し、同じ重複が再発すると`main.py`読込時に明示的なValueErrorになる。
