## 改善点と実装

### 1. デッキ切れ負けの防止（ドローソースの上限/下限）

実ラダーep85174493でミラー戦をデッキ切れ負け（残サイド4枚）。対応:

- `_deck_floor() = max(5, 残サイド数+2)`: 任意ドロー/サーチを止める動的フロア。
  「残サイド数 ≒ 勝ち切りに必要なターン数」で、毎ターンの強制ドロー分を確保する
- フロアを割る消費は「そのドローで今ターン致死（20×手札≥相手HP）に届く」時のみ例外許可
- 適用対象: Run Away Draw（コスト3）/ Hilda・Dawn・Poké Pad・Poffin（コスト2）/
  エンリッチ（コスト4）
- 下限側: 手札が細い時のドローは従来どおり最優先（フロアに余裕がある限り抑制しない）

### 2. クセロシキのたくらみ ×1（-1 ボスの指令）

ミラーでは手札枚数=火力（Powerful Hand=20×手札）。相手手札を3枚まで捨てさせるのは
実質「次のPowerful Handを最大-500点」する妨害。相手の手札が7枚以上のミラーでは
ドローより優先（15500）。非ミラーでも手札9枚以上には13000で撃つ。

※ ユーザー案の「博士の研究」は**このカードプールに存在しない**うえ、存在しても
「自分の手札を捨てる」効果はPowerful Handと真っ向から反する（手札1枚=20ダメージ）ため不採用。

### 3. エンリッチ vs 超エネルギーの貼り分け基準

- エンリッチ（貼ると4ドロー、提供{C}=ワザコストは払えない）:
  **手札5枚以下で展開が細い時に貼る**（8300）。Dudunsparceが回っていて手札8枚以上
  （ドロー源潤沢）なら温存（手札に持つだけで+20ダメ）。デッキ消費4なのでフロア遵守
- {P}が必要なアタッカーがいて手札に超エネがある時は、超エネの貼り付けを優先
- テレパスサイコ（貼るとデッキから基本{P}2体をベンチへ）: ベンチが空いていて
  序盤なら素の超エネより優先（+250）、ベンチ満員/デッキ僅少なら逆（-150）

### 4. ケーシィの前出し条件

素のケーシィ（50HP）を前に出すのは無料サイド献上。**手札にユンゲラー、または
フーディン+ふしぎなアメがある時だけ**優先度を上げる（110）。ないときは
ダンスパ系（140HP壁）より下げる（25 < 40）。

### 5. グッズ優先シーケンス

サポート未使用でサポート札を握っている時、プレイ可能なグッズに+900。
グッズで盤面・手札が動いた後の方がサポートの選択の質が上がる。
