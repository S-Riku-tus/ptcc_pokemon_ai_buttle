# alakazam741_v7.2 戦略概要

この版はv3の攻撃中心の骨格とv7.1の安全条件を維持しつつ、ボスの指令を削除して空いた2枠の再検討結果を反映したものです。クラッシュハンマー2枚を外し、バトルケージと夜のタンカを各1枚増やしました。詳細は`STRATEGY_V7.md`を参照してください。

## 勝ち筋

1. ケーシィからフーディンを早期に作る
2. ノココッチで安全に手札を増やす
3. Powerful Handを毎ターン継続する
4. 最初の後続フーディンラインを攻撃前に確保する
5. 山札が少なくなったら任意ドローを止める

## 行動原則

- 最後のサイドを取るKOは即攻撃
- 余裕のあるKOでは、安全な手札増加や必要な後続準備を行ってから攻撃
- 手札消費で現在のKO圏を失う行動は禁止
- 攻撃可能なフーディンがいる時は、原則として攻撃でターンを終える
- Activeノココッチは、ベンチに攻撃可能なフーディンがいる時だけRun Away Draw
- 最後の1体のRun Away Drawは絶対禁止

## 2枠の再構成

- クラッシュハンマー 2 → 0
- バトルケージ 2 → 3
- 夜のタンカ 2 → 3

クラッシュハンマーはコイン依存で、失敗時にはPowerful Handの手札だけを減らします。代わりに、頻出する不利スタジアムとベンチ攻撃へ対応するバトルケージ、後続フーディンや基本超エネルギーを回収する夜のタンカを増やしました。

## 安全条件

- 盤面全体を含む効果防止を認識
- 0ダメージPowerful Handを禁止
- 低山札時の任意ドローを拒否
- 改造ハンマーは効果防止を剥がして即KOできる時だけ使用
- バトルケージは不利スタジアムまたはベンチ脅威がある時だけ使用
- 夜のタンカは進化ルート・最初の後続・基本超エネルギーを実際に補える時だけ使用
- エネルギー型と技コストを共通ロジックで判定
- 例外時は合法な選択肢へフォールバック
