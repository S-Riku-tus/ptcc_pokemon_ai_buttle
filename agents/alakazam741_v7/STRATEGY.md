## v2の課題（何が起きていたか）

67戦の敗因内訳: サイド取り切られ19 / **山札切れ5** / 盤面全滅2。
山札切れは全てミラー等の長期戦（T15-25）で、「圧倒している試合で山札切れ負け」
というプレイヤー観察と一致。対面別ではミラー14勝7敗（最大勢力21戦=31%）、
Grimmsnarl 0勝2敗、敵スタジアム（Full Metal Lab 14試合、監視塔、Spikemuth等）を
張られた試合が多数あるのに自分のスタジアムは1枚だった。

コード面では `_lethal_now()`（致死判定）が定義済みなのに未使用で、KO攻撃の
スコア上限（~4200）が展開行動（8000〜21500）に常に負ける設計だった。

## 修正の設計プロセス（重要: 仮説→A/B→棄却→再設計）

### 最初の仮説「倒せるなら即攻撃」は棄却された

当初、致死なら攻撃30000+展開全抑制を実装したが、ローカルアリーナで**悪化**:

| 単独変更のアブレーション | vs v2 (200-300戦) |
| --- | ---: |
| 即攻撃強制のみ | **41.5%** |
| 山札予算強化のみ | 49.0% |
| デッキ変更のみ | 55.0% |

理由: **Powerful Handは手札を消費しない**。だから「ドロー・展開で手札を
伸ばし切ってから、ターン終端で攻撃」が構造的に正しく、即攻撃はその上振れを捨てる。

### 採用した設計: 致死維持ゲート

v2の本当のバグを「(a) 手札を減らすプレイで致死圏を割る」「(b) KOを低スコアの
せいで別行動に割り込まれて逃す」に絞り、次で実装:

- `_hand_delta(t, o)`: 行動ごとの手札増減の概算（ドロー系サポ+1 / グッズ・進化・
  エネ貼り-1 / ベンチRun Away Draw+3）
- MAINで致死攻撃が提示されている時、手札を減らす行動は
  `20×(手札-1) ≥ 相手HP`（実行後も致死維持）の時だけ許可。割る行動は10点に抑制
- KO攻撃スコアは2段階: 致死ギリギリ=30000（必ず〆る）/ マージン有=6000
  （v2の4200では夜のタンカ7500等に割り込まれた）/ 勝利KO=常に90000
- 例外: ベンチに「呼べばKOでき、そのサイドで勝ち切る」対象がいる時のボスの指令
  =35000（`_winning_gust_ready()`）
- 手札枚数に火力が依存するのは743のPowerful Handだけなので、ゲートはActive=743限定

## 検討したが棄却した案（A/B根拠つき）

1. **即攻撃強制**: 41.5% vs v2 → 棄却（上記）
2. **フーディン245（ミスト対策テック）+シェイミ343（ベンチ保護）投入**:
   - エンジンの**同名4枚制限**により743+245=「Alakazam」5枚は不受理 → 743を3枚に減らす必要
   - 投入版: crustle 83% / grimmsnarl 74%（v2: 99% / 91%）に悪化
   - 245/343を抜いて改造ハンマー4枚維持: crustle 99%に回復
   → ミスト対策はハンマー4枚の方が強い。コード側の245/343ロジックは将来用に温存
3. **改造ハンマー4→2、ヒカリ4、ボス3等のデッキ変種（D2/D3/D6/D8）**: いずれも
   最終形（D5）の vs v2 68.5%を上回れず
4. **メガディアンシー等への軸変更**: 判断ロジック修正の方が再現性が高いと判断し据え置き

## 事後検証（v3の51戦実ラダー, sub54557078）と分析上の訂正

- **山札切れ負け: 0件**（P0-2は有効） / **ミラー9勝3敗=75%**（P1-3は有効）
- 全体58.8%。新たな最大敗因は「アタッカー連続性の崩壊」→ v4で対応
- **訂正**: v3設計時の「致死ターン234回中177回(76%)未攻撃」という集計は、リプレイの
  action↔observation対応ずれ（応答はsteps[i+1]に記録される）で**過大計上**だった。
  正対応での再集計では v3 の致死放置ENDは0件（v2の真の値は未再集計）。ただし
  本設計の採用判断はリプレイ集計ではなく**アリーナA/B（64.2%）に基づく**ため結論は不変。
  詳細: `docs/alakazam741_v4_analysis.md` の方法論節。
