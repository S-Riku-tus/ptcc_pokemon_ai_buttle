# alakazam_ml_v6

v6 combines the deterministic v3-based fallback policy, the v6 deck and rule
changes derived from 92 v5 ladder games, and a retrained LightGBM ranker.

## Runtime policy

- `fallback_v3.py` remains authoritative.
- ML ranks guarded ACTIVE/MAIN bench, evolution, and attack candidates.
- The default runtime is shadow-only and always returns the fallback action.
- `ALAKAZAM_ML_ENABLE_OVERRIDE=1` is reserved for controlled evaluation.
- Boss, Ability, Trainer, Energy, Retreat, and other strategic actions remain
  rule-only.

## Training corpus

The shadow ranker was retrained from the five top-20 full replay bundles used by
v5 plus submissions `54788067` and `54795292` generated by v5.

- 7 submissions / 6 teams / 3 deck clusters
- 3,250 full replay files / 3,253 expert trajectories
- 171,674 aligned decisions
- 1,972,066 legal candidate rows
- 5 unresolved decisions; alignment rate 99.997%

The two added submissions contributed 92 replays, 3,435 decisions, and 48,118
candidate rows. The candidate remains shadow-only because the added-replay
holdout improved overall Top-1 and Top-3 slightly while Top-1 declined for all
three actions eligible for a future live override.

See `data/ml/alakazam_ml_v6_candidate/TRAINING_REPORT.md` for the feature,
label, weighting, and evaluation details.

## Deck and rules

- Never activate the final Dudunsparce when it is the only Pokemon in play.
- Replace Genesect, Lucky Helmet, and one basic Psychic Energy with three
  Boss's Orders.
- Use Boss only for a same-turn KO on a strategically better Bench target.
- Preserve an equal or better Active KO.

See `V5_LOG_ANALYSIS_AND_V6_CHANGES.md` and `VALIDATION_REPORT_V6.md` for the
rule-analysis history.
