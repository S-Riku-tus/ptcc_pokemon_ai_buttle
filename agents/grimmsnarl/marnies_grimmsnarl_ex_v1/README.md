# Marnie's Grimmsnarl ex v1

上位対戦ログから復元した60枚を使う、マリィのオーロンゲex専用エージェントです。

主な方針は、Punk Upで現在の攻撃役へ2エネ、次の進化元へ最大3エネを集中し、
MunkidoriのAdrena-BrainとShadow Bulletのベンチ30点を同一のサイド取得ルートへ
統合することです。Froslassは特性持ちが多い盤面で優先し、Boss's Ordersは原則として
同一ターンの確定KOがある場合だけ使います。

ローカル実行名は `marnies_grimmsnarl_ex_v1` です。

評価結果とデッキ比較は `experiments/marnies_grimmsnarl_ex_v1/RESULTS.md` にあります。
