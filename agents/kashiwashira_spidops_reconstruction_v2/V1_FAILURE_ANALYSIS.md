# Spidops再現版 vs kashiwashira 1位版 ログ比較分析

## 分析対象

- 再現版 submission 54655021: 公開43戦、19勝24敗、勝率44.2%
- 1位版 submission 54603674: 公開99戦、71勝28敗、勝率71.7%
- validation戦は除外
- 両者のdeck.csvは60枚完全一致

## 結論

レート差の主因はデッキではなく意思決定ロジックである。特にPoké Padの解決処理には明確な実装バグがあり、28回すべてで合法候補を取得せず空選択していた。これが盤面展開、Spidops進化、特性加速、主攻撃の継続性を連鎖的に低下させた。

序盤の初攻撃だけは再現版が遅くない。T2攻撃率は45.2%対44.4%、T3は46.2%対44.9%。差は中盤のエンジン継続性である。

## P0-1 Poké Padの空選択バグ

再現版:
- 解決28回
- 合法候補108件
- 選択0件
- 空選択28/28

1位版:
- 解決236回
- 選択236/236
- Tarountula 103、Spidops 83、Mimikyu 30、Articuno 20

原因:
`score_to_hand()`がTransceiverとPoké Padを同じ分岐へ送り、Poké Padで提示されるPokémonを`supporter_search_value()`へ渡す。非Supporterは-1になるため、任意選択で全候補を拒否する。

さらにPoké PadはItemなのに、Supporter使用済みの場合にプレイ禁止としている。

## P0-2 Factory特性を拒否しすぎる

- 再現版: 提示66回、選択16回、24.2%
- 1位版: 提示165回、選択154回、93.3%

再現版は手札7枚以上で拒否し、通常攻撃より低いTierに置く。1位版は安全な山札枚数ならほぼ毎回使い、約30.6%は同ターン攻撃、28.5%は同ターンKOへ接続している。

## P0-3 Giovanniの非KO使用

- 再現版: 60回、同ターン攻撃+KO 26回、43.3%
- 1位版: 111回、同ターン攻撃+KO 92回、82.9%

再現版はKOできないGiovanniにもDISRUPT点を与える。Giovanniは原則として確定KO、勝利KO、または極めて限定的なロック解除に絞るべき。

## P1 Supporter検索の優先順位

Transceiverの選択:
- 再現版: Proton 53%、Giovanni 33%、Ariana 11%
- 1位版: Ariana 54%、Proton 22%、Giovanni 17%

再現版は盤面5体未満ならProtonを固定的に優先する。一方1位版はArianaを主に選び、盤面を維持しながら手札を回復する。

カード使用/試合:

|---|---:|---:|
| Poké Pad | 3.2% | 29.5% |
| Bug Catching Set | 0.0% | 29.0% |

| Factory | 0.0% | 30.6% |

再現版では通常の非KO攻撃がBUILD/VALUEより上位で、攻撃可能になるとすぐ攻撃してターンを終える。勝利KOは最優先、通常KOは高優先としつつ、非KO攻撃は安全な展開・ドロー・加速より後へ置き、最後に攻撃する構造へ変更する。

## P1 初期Activeとピボット

TarountulaとMimikyuが同時に初期Active候補だった局面:
- 再現版: Tarountula 5/5
- 1位版: Mimikyu 12/12

1位版はMimikyuを壁・ピボットとして置き、MimikyuからSpidopsへ94回移動した。再現版は13回。再現版はActiveが攻撃可能なら退避を全面禁止しているため、ベンチのSpidopsでKOできる局面でも弱い攻撃を選び得る。

## 対面差

対戦相手の分布は同一ではないため、44.2%対71.7%を完全なA/Bとは扱えない。ただし共通対面でも差がある。

- Mega Kangaskhan ex + Crustle: 再現版0-4、1位版15-10
- Fezandipiti ex + Alakazam: 再現版3-0、1位版31-6（再現版は小標本）
- Mega Lucario ex系: 再現版4-4、1位版2-1（双方小標本）

Crustle対面は、Mewtwo exへ寄せず、一進化・非exのSpidopsを継続して作る必要がある。

## 改善順序

### S1
Poké Padの候補評価とSupporter使用済みゲートを修正。他は変更しない。

### S2
Factory特性を安全な山札枚数ならほぼ常時使用。非KO攻撃より前へ。

### S3
Giovanniを確定KO中心へ限定。TransceiverはArianaを基本に、Protonは初動不足時だけ。

### S4
通常非KO攻撃を安全な展開・ドロー・特性より後へ。ターン終端で攻撃。

### S5
初期ActiveをMimikyu優先へ。現在のActiveが攻撃可能でも、ベンチがKOまたは明確な高打点なら退避可能にする。

### S6
上記を固定してからCrustle等の対面固有分岐を追加する。

## 最初はデッキを変えない

60枚は同一であり、ロジックに明確なバグがある。カード変更を混ぜると改善原因を分離できない。まず同じ60枚でS1〜S5を段階的にA/Bし、その後にカード変更を検討する。
