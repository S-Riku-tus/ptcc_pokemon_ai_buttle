# 上位フーディン8チーム・全対戦ログ統合分析

## 1. 対象と結論

8チームの公開対戦 **793試合**を、デッキ60枚、先後、ターン、盤面、進化、エネルギー、カード使用、ノココッチ循環、攻撃、勝敗理由まで同じ基準で再集計した。validation/self-playは除外した。

主要結論は次のとおり。

1. 8デッキには **54枚の完全共通コア**があり、上位差の中心は残り6枠よりも行動優先順位にある。
2. 最も再現性の高い勝ち筋は、1ターン目に約4体を準備し、2ターン目に攻撃へ変換し、3ターン目以降はほぼ毎ターン攻撃すること。
3. Yushin Ito型は「高速・高攻撃率・山札切れを許容」、Majkel1337型は「ノココッチ循環を深く回しつつ長期戦を管理」という異なる上位解を示す。
4. 同一60枚でも、Yushin Itoはbonoより平均初攻撃が約0.57自ターン早く、攻撃ターン率も約76%対60%。デッキよりロジック差が大きい。
5. 最大の苦手はMega Kangaskhan ex系で、全体勝率26.4%。敗戦64件中48件が山札切れであり、通常の高速対面とは別の終盤ロジックが必要。

## 4. ターン進行の共通パターン

### 1回目の自ターン

- 終了時盤面は平均3.76〜4.08体。
- 手札は約5.4〜6.1枚、山札は約41.7〜42.6枚。
- 主な行動はポフィン、ポケパッド、ケーシィ/ノコッチの展開、ケーシィへのテレパスサイコエネルギー。
- 初手Activeはケーシィまたはノコッチが中心。キチキギスex/シェイミActiveは初攻撃が概ね3ターン前後まで遅れるため、事故時の避難先。

### 2回目の自ターン

- 盤面は平均4.64〜5.34体。
- 攻撃率はチーム差が最大で、bono/Rmy約49%、Majkel67%、LiamK81%。
- 「アメでフーディン」「ユンゲラー経由」「ノココッチ進化→循環」「エネルギー」「攻撃」を同一ターンにまとめる。

### 3回目以降

- 3ターン目攻撃率は75〜95%、4ターン目84〜96%。
- フーディン攻撃前には平均約4.3〜4.8個の行動を行っている。つまり上位は即攻撃一辺倒ではなく、**攻撃を保証したうえで安全な進化・ドロー・妨害を先に処理し、最後に攻撃する**。
- 重要なのは「攻撃より全行動を禁止」ではなく、「前処理をしても最終的に攻撃を失わない」不変条件。

## 5. 同一デッキから分かるロジック差

### Yushin Ito / bono / Rmy

同じ60枚だが、Yushinは初攻撃2.08、攻撃ターン率76.2%。bonoは2.65・59.6%、Rmyは2.49・65.6%。

- Yushin：3ターン目攻撃94.9%、5ターン目96.6%。攻撃へ切り替える判断が最も早い。
- bono：夜の採掘場1.04回/試合、ヒカリ1.38、ヒルダ1.15、クセロシキ1.33と補助行動が多く、攻撃が遅い。
- Rmy：クセロシキ1.57回/試合、キチキギスex展開0.72回/試合で、妨害・技術札寄り。

Yushinは32敗中23敗が山札切れであり、安全性を犠牲にテンポを最大化している。これは模倣時にそのまま採用すべき欠点ではないが、「山札切れをゼロにするため攻撃速度を落とす」より上位に到達しやすいことを示す。

### Majkel1337 / matsurih

同じ60枚。Majkelはノココッチ循環4.59回/試合、matsurihは2.92回。Majkelは平均試合長も約10自ターンで、matsurihの7.76より長い。

Majkelは循環を多用する一方、山札切れ敗は4件だけで、matsurihは11件。つまり「低山札なら一律停止」ではなく、ノココッチが自身と進化元を山札へ戻す純増分、残りサイド、次のKOまでのターンを含めて判断している可能性が高い。

## 6. カードごとの実戦運用

### ノココッチ

- Majkel 4.59回/試合、bono 3.05、Yushin 2.71、THIRD 2.03。
- Yushin/matsurih/LiamKでは使用ターンの約79〜86%で同ターン攻撃。
- Majkelは長期戦・再建ターンでも回すため同ターン攻撃率58%。

ロジック化では、単純な山札枚数閾値ではなく、`能力解決後の実効山札枚数`と`残り勝利ターン`を比較する。PRESSURE状態では、使用後も攻撃可能であることを必須にする。

### ふしぎなアメとユンゲラー

フーディン進化のうちアメ直進化比率は26〜37%で、過半数はユンゲラー経由。上位はアメを常時最優先にせず、今ターンの攻撃完成や倒された直後の再建に使い、通常時はユンゲラーを並行育成する。

### エネルギー

- テレパスサイコは序盤のケーシィと、完成後のフーディンへ。
- 基本超はフーディンへの付与が最多。
- エンリッチはノコッチへの付与が多く、主アタッカー専用ではない。

付与先評価は「今ターン攻撃可能」「次ターン確定攻撃」「ドロー/ピボット価値」の順にする。

### 改造ハンマー

0.8〜1.4回/試合。使用ターンの約65〜87%で攻撃を継続しており、上位は妨害だけでターンを終えない。`相手特殊エネルギーを落とす価値 > 手札1枚消費による火力低下`かつ`攻撃を維持`する場合に限定する。

### クセロシキ

0.66〜1.57回/試合。使用ターンの75〜85%で攻撃。Rmy/eiは使用量が多いがScoreは上位2チームより低く、「使えるから使う」は支持されない。ミラー、大量手札、攻撃維持、致死を失わないことを条件にする。

### ボスの指令

全デッキ3枚。Yushinは使用ターン94%で攻撃、60%で同ターンKO。matsurihは93%攻撃、76%KO。一方bonoは64%しか攻撃へ接続していない。

これはカードの自動採用を意味しない。以前の懸念どおり実装難度が高く、採用するなら次だけに限定する。

1. 呼び出し後に勝利または確定KO。
2. 現Activeよりサイド期待値が厳密に高い。
3. 効果無効・壁を回避して攻撃が通る。
4. 上記を満たさない場合は使わない。

### スタジアム/技術札

bonoは夜の採掘場を1.04回/試合と多用し、同一デッキのYushin 0.52、Rmy 0.64より攻撃が遅い。THIRDのジャミングタワー、LiamKのニュートラルセンターも中核ではなく対面依存。スタジアムは「場に出せる」ではなく、即時のロック解除/KO/明確な被害防止がある場合だけ。

### Mega Kangaskhan ex

87戦23勝、勝率26.4%。敗戦64件中48件が山札切れ。攻撃開始の遅さより、長期戦でノココッチ・ドロー・検索を回し続けることが問題。

- `turns_to_deckout`と`turns_to_take_prizes`を比較する。
- optional draw/searchは、KOを作るか勝利ターンを短縮するときだけ許可。
- 高HP Activeを倒せない場合のボスは、確定KOできるベンチがある場合のみ。
- 回復札/循環札を早期に使い切らない。

### Team Rocket Spidops/Mewtwo

43戦勝率39.5%。攻撃回数が非常に多く、0ダメージ/低進展攻撃も多い。保護・壁状態を明示的に検出し、通常PRESSUREではなくLOCKEDへ移行する。

### Grimmsnarl / Starmie系

敗戦は主にサイドレース。負け試合は攻撃回数が少ないため、山札保護より2体目フーディン確保とT2/T3攻撃を優先する。

### ミラー

247戦勝率66.4%。勝ち試合は攻撃率79%、負け試合55%。ミラーはクセロシキの有無以上に、攻撃を欠かさないことが主要差。

## 8. 実装へ落とす推奨状態機械

### SETUP

攻撃可能なフーディンがいない。

1. 今ターン攻撃できるフーディン完成。
2. 必要エネルギー。
3. 2本目のケーシィ/ユンゲラー。
4. ノコッチ1体。
5. 技術ポケモンは対面条件が成立した場合のみ。

盤面5体を固定目標にしない。ログ上のT2盤面は約5体だが、役割が揃った結果であり目的ではない。

### PRESSURE

攻撃可能なフーディンがいる。ターン開始時に「最終行動として攻撃する」予約を置く。

攻撃前に許可する行動は、

- 現在のKO率/打点を上げる。
- 次のフーディンを確定する。
- 攻撃を失わずに手札を増やす。
- 攻撃を失わずに高価値妨害を行う。

のいずれか。行動後に攻撃不能、致死喪失、必要エネルギー消費、手札減少でKO圏外になるなら拒否する。

### RECOVER

フーディンを失った直後。アメ/ユンゲラー、夜のタンカ、聖なる灰、エネルギーへ処理を限定し、スタジアムや追加妨害を後回しにする。

### LOCKED

攻撃が0ダメージ/効果無効。

1. 改造ハンマー等で即解除。
2. 厳格なボスで通る対象へ変更。
3. 解除不能なら無意味なドローと攻撃を止め、山札/盤面を保存。

### ENDGAME

`残り山札`, `ノココッチで戻る枚数`, `残りサイド`, `現在の最大打点`, `相手を倒す必要ターン`を同時評価する。

## 9. 推奨する行動選択の形

```python
state = classify_state(obs)
attack_plan = best_legal_attack(obs)

if state == PRESSURE:
    reserve_attack(attack_plan)
    while True:
        action = best_pre_attack_action(obs)
        if action is None:
            break
        if not preserves_attack(action, attack_plan):
            reject(action)
            continue
        if not improves_current_or_next_prize_plan(action):
            reject(action)
            continue
        execute(action)
        attack_plan = recompute_attack_plan(obs)
    return execute(attack_plan)
```

平坦な単一スコアではなく、`攻撃予約`と`前処理ゲート`を分離する。上位ログの「4〜5行動してから攻撃」を再現しつつ、補助行動だけでターン終了する問題を防げる。

## 10. 最も移植価値が高い要素

1. YushinのT2/T3攻撃切替。
2. Majkelのノココッチ循環と長期戦の山札管理。
3. matsurihの妨害後攻撃への高い接続率。
4. LiamKの早いT2攻撃と、技術枠を増やしすぎない構成。
5. bono/Rmyを反面教師にした、スタジアム・妨害・展開の打ち切り条件。

最終的には、Majkelの60枚を基準にするか、Yushinの60枚を基準にするかより、**Yushin型の攻撃テンポ + Majkel型のENDGAME管理**を組み合わせることが重要である。
