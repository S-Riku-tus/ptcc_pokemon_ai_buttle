## 決定的な発見1: 致死ターンの浪費（※冒頭の訂正参照: 件数は過大計上）

Powerful Hand(20×手札)で相手Activeを今すぐ倒せる状態を「致死」とすると、

- 致死状態を含むターン: **234ターン**
- うち攻撃せずに終えたターン: **177ターン (76%)**

例(ep85184806 T5): 手札8=160ダメ vs 相手フーディン110HP。ボス→アメ→ケーシィ→
エネ→ポフィンと展開を続け(手札15=300ダメまで肥大)、一度も攻撃せずターン終了。
この試合は最終的に山札1枚まで消耗して3-1で敗北。

原因はスコア設計: KO攻撃は最大~4200点なのに対し、展開行動は8000〜21500点。
`_lethal_now()` は定義済みだが未使用だった(他AI分析の指摘とも一致)。

## 決定的な発見3: テックカード追加はA/Bで棄却

他AI分析の推奨だった `Alakazam 245`(Mist対策)/`Shaymin 343`(ベンチ保護)投入は悪化:

- 同名制限: 743×4 + 245×1 = 「Alakazam」5枚は**デッキ不受理**(エンジンが同名4枚制限)。743を3枚に減らす必要がある
- 245/343入りデッキ: crustle 83% / grimmsnarl 74% (v2: 99% / 91%)
- 245/343を抜きハンマー4枚維持: crustle 99%に回復

→ Mist/Rock対策は改造ハンマー4枚維持の方が強い。コード側の245/343ロジックは温存
(将来の再検証用)だが、デッキには入れない。
