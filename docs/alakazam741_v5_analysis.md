## 5. ユーザー考察の検証結果

### 5.1 v4を見た時点での私(ユーザー)の改善仮説

以下は、v4の実ラダー結果を見たあとに「v5ではここを直したい」と考えた
ユーザー所感の記録である。後段の表は**ログ全数分析に照らした検証結果**であり、
この節はその前段にあった設計メモとして残す。

1. **アメ進化→そのターン攻撃をもっと強く優先すべき**
   - このターンに不思議なあめからフーディンへ進化し、そのまま攻撃できるなら、
     基本的には進化しないより進化して倒した方がよい。
   - 相手の主力が今まさに場にいて、その主力を倒せるなら優先度はさらに高い。
   - 相手の主力が場にいない場合でも、「進化せず誰も倒せない」より
     「進化して非主力でも1体倒す」を優先したい。
   - 相手の手札や次ターンの完全な展開は読めない以上、見えない情報を深読みしすぎず、
     今ターンの確実な打点・確実なサイドを重く見るべき、という仮説。

2. **ボスの指令2枚は一度外し、対効果無効の札へ寄せたい**
   - 当時の所感では、ボスの指令を友好的に使えておらず、扱いが難しいと感じた。
   - そのため、v4の天敵だったロケット団のフリーザーやミストエネルギー系への
     対策を優先し、ボス2枚を別の役割札へ置き換えたいと考えた。
   - 候補としては、**メガディアンシーex / ノココッチex / ガチグマex** など、
     「フーディンの攻撃が通らない相手に別軸で触れるポケモン」を想定。
   - さらに、2枠のうち1枠は上記の対策ポケモン、もう1枠は
     **ポケパッドを1枚増やす** 方向を考えていた。

3. **次ターンにフーディン系が倒されるなら、盾への退避をもっと行うべき**
   - フーディンがこのデッキの生命線なので、次の相手ターンで
     ケーシィ/ユンゲラー/フーディンのラインが倒されるのが明白で、
     かつベンチにフーディン以外がいるなら、そのターン中に交代して守りたい。
   - ベンチにノコッチ系がいる場合は、まずそれを最優先で前に出して盾にする。
   - ただし、ベンチにいるのがexポケモンだけのときは、2サイドを取られて負ける
     パターンもあるため、単純な「常に交代」ではなくサイド計算が必要。
   - 一方で、守りを優先しすぎて「今の相手を倒せるのに倒さない」のも問題で、
     次のような例外はあると考えていた。
   - アクティブがケーシィ/ユンゲラーで、進化しなくても今の相手を倒せて、
     さらにベンチに次ターン以降フーディンへ繋がる札が残る場合。
   - アクティブがフーディンで、今の相手を倒せるうえ、仮に次ターンに
     そのフーディンが倒されても、返しのターンに次のフーディンで再度
     相手を倒し返せる見込みがある場合。
   - 背景には、「相手の主力を倒す→こちらのフーディンが倒される→
     次のフーディンでまた倒す」という交換ループが続く対面では、
     相手主力の残り枚数をある程度数え、そのループに耐えられるかを
     意識したい、という考えがあった。

4. **Run Away Draw は「使わない条件」だけでなく「使う条件」も強めたい**
   - 場にノココッチしかいない、またはベンチが細く、特性を使うと
     次の相手ターンで即敗北する形では使ってはいけない。
   - しかし逆に、ログを見ると**ベンチ3体以上でも使っていない**場面があり、
     これは保守的すぎると感じた。
   - 当時の所感では、**ベンチに2体以上いるなら基本は確定で使ってほしい**
     という方向に寄せたいと考えていた。

## 6. 私(ユーザー)が気づいていなかった問題

1. **自滅の引き金は `_item_locked()` の状態誤検知**。「手札にグッズがあるのに
   PLAY候補に無い=アイテムロック」という推定が、単に対象がないだけの
   改造ハンマー/アメ等で誤発火し、前ノココッチ特性(14000点)を許可していた。
   4敗全てこの経路。85430151ではフーディン+ユンゲラー+アメを握った勝ち試合を
   これで捨てている。
2. **盤面全体の効果無効の未認識**(コードは対象自身+貼りエネしか見ない)。
   0ダメ連打だけでなく「勝っているつもり」(`_deck_preserve`の致死誤認)や
   ボスの対象評価まで狂う。
3. **山札切れ2敗は0ダメ対面とセット**。0ダメ中もノココッチ/ACTIVATEで
   掘り続け、「致死に届くなら山札フロア割り込み可」の例外が
   誤った致死判定で常時発動していた。
4. **序盤盤面数が最強の勝敗予測因子**(5体以上86.4% vs 4体以下22.6%)。
   ベンチ切れガード(2体以下)だけでは不足。
5. **コードに245フーディン対応が実装済みなのにデッキに無い**(別AIの指摘通り)。
   ただしA/B再検証の結果、743を3枚に減らすコストが大きく**採用は見送り**が正しい
   (ミラー直対37.3%/600戦。v3での同結論を再確認)。「コードとデッキの不一致」は
   ロジック温存のまま許容する。

## 9. 優先して修正すべき点 → v5で実装した変更

**P0 (即修正・実装済み)**
1. 最後の1体ノココッチ特性 → -100000。ロック脱出トリガー廃止、
   「ベンチに攻撃可能フーディン」時のみ前の特性を許可。盤面2体+補充なしも禁止。
2. 全体効果無効を特性テキストスキャンで検出(`GLOBAL_EFFECT_PROTECTORS`)。
   スコープ解析(benched/basic/Team Rocket's)付きで、保護対象外は正しく殴る。
3. no-damage-path: 解除見込みなし→任意ドロー停止。貼りミスト系はハンマー
   未消耗+山札余裕あり→掘り続行(受け身化の副作用対策)。
4. `_deck_preserve`/`_lethal_after_draw` の致死誤認修正(効果無効を考慮)。

**P1 (デッキ・実装済み)**

### リーリエの決心ロジック(実装)
- 対象手札 = 8(自分サイドちょうど6枚) / 6(それ以外) ※カードテキスト進拠
- 禁止: 致死攻撃が提示されている / 完成コンボ(フーディン+ユンゲラー or
  ケーシィ+アメ)保持で手札3枚以上 / 手札が目標-2より太い
- 14200(ヒルダ12500より上): 手札-1≦目標-3 かつ 攻撃可能フーディン不在
- 8600(ポケパッド8500の直上): 手札-1≦目標-2 — たね/進化/エネ/ハンマー等
  「今使うべき札」(≧13000帯)を消化した後に発動する順序制御
- サーチ札(ポケパッド等)はスコア上リーリエより下=リーリエ後に使用
