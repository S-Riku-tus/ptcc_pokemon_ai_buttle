## v5を見て感じたロジック改善点

1. **改造ハンマーの使い方をかなり絞るべき**
   - フーディン側がそのターン攻撃できないのに、改造ハンマーだけ使ってターン終了する場面があった。
   - 基本ルールとして、**相手Activeのミストエネルギー等でフーディンの攻撃が無効化されていて、ハンマーを使えばそのターンに攻撃が通り倒しきれる時だけ使う**、という方針に寄せたい。
   - 相手ベンチに対しても同じで、「特殊エネが見えたらとりあえず剥がす」は避けたい。
   - 例外として、使わないと相手の技でこちらのフーディンが倒され、そのまま負けに直結するような重大局面では、阻止目的で使う余地は残したい。

2. **クセロシキのたくらみは、良い使い方を残したまま“追加条件”を入れたい**
   - 既存の強い使い方はそのままでよい。
   - 追加で、**全体として形勢が負けている時**で、かつ**他に使うべきサポーターが無い/使わない方が良い**なら、相手手札5枚以上で使ってよいと考えた。
   - また、単純な条件として、**まだクセロシキを使っていない**か**手札に2枚ある**なら、相手手札6枚以上で使ってよい、というルールも欲しい。

3. **フーディンで攻撃すべきなのに、のこっち系へ逃げて終わるのを直したい**
   - v5では「次ターンにフーディン系が倒されるなら、のこっち系に交換して守る」条件を入れたが、
     それが先に走ってしまい、**攻撃せずに交換だけしてターン終了**になる場面があった。
   - そのため、退避ロジックの前に、まず**今のフーディンで攻撃すべきか**を判断したい。
   - 特に、今のフーディンで相手を倒せなくても、ベンチに「次のフーディンとして出て相手を倒せる後続」がいるなら、
     今のフーディンは交換せず攻撃して、次ターン倒された後に後続フーディンで取り返せばよい、という発想。
   - 背景として、攻撃しないまま守り続けても、相手に居座られて結局のこっち系を狩られ続けるだけになりやすい。

## v5を見て感じた敗因整理

1. **全体としては v5 は v4 よりかなり良く、主敗因は初手事故寄り**
   - 体感では、負けの多くは初手事故に寄っている。
   - 特に、**のこっち系しかいない初手**が目立つと感じた。
   - 現状 `のこっち4 / ノココッチ3` だが、1試合で実際に多く並べるわけではなく、
     別の「攻撃もできて盾にもなるたねポケモン」が欲しいという発想になった。
   - できれば ex 以外が理想だったが、当時の候補整理としては
     `のこっち -1 / ノココッチ -1 / メガディアンシーex +1 / リーリエの決心 +1`
     を考えた。

2. **ミストエネ複数枚で止められ、ハンマーが来ず山札切れする負け**
   - 典型例として、ミストエネルギーを2枚付けられ、改造ハンマーが十分に来ず、
     毎ターン掘るしかなくなって山札切れする、という負け筋を重く見た。
   - このため、**「あと何ターンで相手の残りサイドを取り切れるか」を踏まえて、
     山札が下限に近づいたらグッズ/サポーターを止める**ような条件が必要だと考えた。
   - ここでは「自分が負けることを避ける」だけでなく、
     「勝つために最低何ターンぶんの通常ドローが必要か」を山札フロアに含めたい、
     という考え方だった。

## v6で反映した方向

上の所感は、最終的に `v6` では次の形で反映した。

- 改造ハンマーは「倒しきり」または「致死阻止」に用途を限定。
- クセロシキは既存の強い使い方を維持しつつ、形勢不利時と手札枚数条件で追加発動。
- 退避判定の前に「今のフーディンで攻撃すべきか」を評価。
- 山札切れ回避のため、1枚のハンマーで解除不能な no-damage-path では掘りを停止。
- デッキは `のこっち -1 / ノココッチ -1 / リーリエ +1 / メガディアンシーex +1`
  の方向で試す。
