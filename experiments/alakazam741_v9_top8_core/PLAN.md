# PLAN — alakazam741_v9_top8_core

## 目的

上位フーディン8チーム・793試合分析の「汎用コア」を、対面別分岐なしで再現する新実装を作り、v8に対する優位とKaggle Rating 1000+の足がかりを狙う。デッキはv8と完全同一の60枚に固定し、**ロジック差だけ**を測定する。

## 仮説

v8は Phase/Tier の平坦スコアに、固定山札フロア `max(8, prizes+3)` と `手札12・山札14` 固定停止を持つ。これは上位ログが示す「攻撃を予約したうえで安全な前処理を行い最後に必ず攻撃」「実効山札に基づく動的なドロー停止」を十分に表現できない。次を導入すれば、初攻撃・攻撃率・後続再建・終盤管理が上位側に寄り、v8を上回るはず。

1. 毎MAINで一つの状態（SETUP/PRESSURE/RECOVER/LOCKED/ENDGAME）を決める状態機械。
2. 明示的な攻撃予約 `_attack_reserved` と、予約を壊さず打点/後続/手札/妨害を改善する行動だけを攻撃より上に置く前処理ゲート。
3. 固定フロアを撤廃し、`turns_to_deckout`（実効山札=山札+ノココッチ復帰+聖なる灰復帰）と `turns_to_win`（サイド数を実ゲーム長で補正）を比較する動的山札管理。

## 検証手順

1. 静的検証: `py_compile` → `validate_agent` → v9 golden tests（22項目）→ 全 `pytest`。
2. 席交換均等（`local_arena` の `a_first = g%2==0`）で 200 戦ずつ: v9 vs v8 / v3 / v2。
3. `scripts/analyze_alakazam_policy_metrics.py` で行動指標（初攻撃・攻撃率・ノココッチ・退避・0ダメージ・攻撃可能END・山札切れ・fallback・クラッシュ）を集計。
4. 目標未達なら対面別分岐を追加せず、初攻撃・攻撃率・ドロー停止・後続再建のどこに差があるかを診断。

## 合格基準（第一段階）

- 安全: クラッシュ / 違法 / policy fallback / observation fallback / 最後の1体ノココッチ特性 / 0ダメージPowerful Hand / 攻撃可能なのにEND / 現在KOを手札消費で失う = すべて0。
- 行動: 初攻撃 ≤2.3自ターン、2回目自ターンまで攻撃率 ≥65%、全自ターン攻撃率 ≥72%、退避 ≤0.3/試合、退避後攻撃率 ≥90%、ノココッチ特性 2.5–4.5/試合（目安）。
- 対戦: v8 に ≥55%、v3 に ~50%前後、（可能なら）v2。
