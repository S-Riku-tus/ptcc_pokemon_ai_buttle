# Grimmsnarl ML v2.1 evaluation

## 結論

v2.1 は、通常の教師ログ全体では v2.0 とほぼ同等、狙いだった壁関連局面では明確に改善した。採用モデルは全21教師を等重みで学習した `ranker_v21_base.txt`。実行時の教師IDは v2.0 と同じ 16494330（leaderboard 1077.6）に固定した。

1220教師へ直接固定する案は採用していない。等重みモデルの時系列 test で 16371703 の再現率は78.54%に対し、16494330は91.96%だったためである。前者への切替は「強い教師を選ぶ」より「再現できない判断を大量に出す」影響が大きい。

## 変更した意味論

- Shadow Bullet の有効ダメージに壁Ability、弱点・抵抗、Neutralization Zoneを反映。
- ベンチへのダメカン配置に Battle Cage を反映。
- `DAMAGE_COUNTER` は相手への配置、`REMOVE_DAMAGE_COUNTER` は自分のダメージ源選択として分離。
- Boss指令について、呼べる対象、即KO対象、壁を退かせて有効打を作る対象を分離。
- MLから外した文脈でもルール選択をターン履歴へ記録。
- teacher-forced 評価でモデル予測を自己履歴へ混入させず、各試合リセット後も teacher-forced を維持。
- 壁攻撃集計を「任意のattack action」ではなく Shadow Bullet (`attackId=937`) に限定。

## 学習アブレーション

同じ per-team chronological split、seed、特徴、LightGBM設定で比較した。

| 学習条件 | validation Top-1 | test Top-1 | MAIN test | context 7 test | 判断 |
|---|---:|---:|---:|---:|---|
| 等重み baseline | 84.92% | 84.84% | 79.81% | 84.03% | 採用 |
| 勝利ログ 1.25倍 | 84.65% | 84.63% | 79.56% | 83.18% | 棄却 |
| レート重み 最大1.5倍 | 84.70% | 84.64% | 79.59% | 83.60% | 棄却 |

勝敗は初手・相手・引きの影響を含むため、意思決定品質の弱いラベルだった。レート重みも、高レート教師間の異なる流儀を単一モデルへ平均するだけで、held-outの一手再現率を改善しなかった。

## ランタイム比較

固定教師16494330の時系列 test 18試合（1,420決定）:

| 指標 | v2.0 | v2.1 | 差 |
|---|---:|---:|---:|
| 全コンテキスト | 91.62% | 91.34% | -0.28pt |
| MAIN | 89.71% | 88.92% | -0.79pt |
| REMOVE_DAMAGE_COUNTER系 | 91.67% | 95.83% | +4.16pt |
| Boss系 context 21 | 96.34% | 97.56% | +1.22pt |

全体差は1,420決定中4手で、統計的な優劣を主張できる幅ではない。一方、修正対象のダメカン意味論では方向通り改善した。

壁関連60試合（5,573決定）:

| 指標 | v2.0 | v2.1 | 差 |
|---|---:|---:|---:|
| 全コンテキスト | 88.53% | 89.61% | +1.08pt |
| MAIN | 86.07% | 87.39% | +1.32pt |
| 壁不在分類 | 84.13% | 85.10% | +0.97pt |
| 有効打なし壁 | 85.80% | 87.33% | +1.53pt |
| サイド取得可能 | 91.94% | 93.55% | +1.61pt |

攻撃回数（agent / teacher）は、壁不在67/57、有効打なし壁193/204、サイド取得可能11/11。単純な「壁なら攻撃禁止」にはしていない。上位教師自身が有効打なしに見える攻撃を選ぶ場合があり、Bossや後続手まで含むタイミングを学習させる方が整合的だからである。

context 8 は validation が11件しかなく、既定0.60ゲートでは一度ルールへ戻った。しかし壁集合の単一選択でルール31.25%、ML87.50%だったため、外部評価を根拠に0.50ゲートでMLへ戻した。最終JSONにはゲート値と routed contexts を保存している。

## Self-play

同一seedを試合ごとに再設定し、座席を交代した。

- v2.1 vs v2.0: 21-19（52.5%）、エラー0、違法選択0、fallback 0。
- v2.1 vs v1: 25-5（83.3%）、エラー0、違法選択0、fallback 0。
- v2.1平均推論時間: 28.85-29.54 ms/move。

ローカルself-playはレート1200の証明ではない。今回言えるのは、壁局面の再現性を改善しながらv2.0相当の対戦力を維持し、v1への優位も保ったことまでである。

## 次の実験

1. v2.1をladderへ出し、最低50-100試合でレート、先後、対面、壁遭遇、Shadow Bullet空振りを記録する。
2. 1000未達なら、全体再重み付けではなく「高レート教師と低レート教師が同一状態で分岐する決定」だけを抽出し、pairwise preferenceまたはresidualで学ぶ。
3. 1000を安定して越えた後、16371703専用モデルを別challengerとして学習する。現在の共通モデルに教師IDだけを差し替える実験とは分ける。
