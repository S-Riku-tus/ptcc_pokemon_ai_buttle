# Grimmsnarl ML v21

## 結論

v21 は v20 を土台に、(1) 壁対面で最速の突破ルートを消費しない `wall_break` 修正、
(2) retreat lock を表す 6 特徴の追加、(3) Prize conversion を含む hard-state の
拡張、(4) early stopping patience の是正、の 4 点を入れた版である。

**重要な訂正**: 前回の分析で「900-1000 帯で v20 が v19 を上回る (Fisher p=0.027)」
と報告したが、これは v19 の弱かった方の提出とだけ比べた値だった。v19 の 2 提出を
プールすると 17-15 対 15-6、**p=0.25 で有意でない**。しかも同一バイナリの v19 二提出
だけで同帯が 14-7 対 3-8、p=0.062 になる。1 提出 40-50 戦では帯別 p<0.05 でも判定
根拠にならない。**v20 が v19 より強いという結論は撤回する。**

## 1. wall_break: 「最後の 1 体」ではなく「最速のルート」を保存する

v16-v20 の `_spends_last_breaker` は `len(breakers) != 1`、すなわち Morgrem /
Impidimp の**実数**で判定していた。エネルギー 0 の 2 体目がいるだけでガードが解除
される。episode 92168220 turn 13 がまさにそれで、Crustle が Active、Shadow Bullet
は 0 ダメージ、盤面には Dark 2 の Morgrem と Dark 0 の Morgrem、そして ready な
Grimmsnarl ex。唯一攻撃できた Morgrem を進化させ、9 回の死に swing、0 サイド、
山札切れで敗北した。

v21 は `_breaker` が既に持つ ETA 計算を再利用し、「進化先が最速ルートで、他により
速い breaker が無い」ときに拒否する。v17 が守っていたケースを失わないよう、
`len(breakers) == 1` は論理和として残した。

保存 529 戦・251,503 合法入力の全掃引:

| | v20 | v21 |
| --- | ---: | ---: |
| 拘束される合法入力 | 1,614 | 1,662 |
| 拘束 prompt | 451 | 474 |
| **保存行動への実変更** | **57** | **71** |
| errors | 0 | 0 |

差分 14 件は 13 episode に分布し、**うち 10 敗**、12 件が Kangaskhan/Crustle、
1 件が Ogerpon。92168220 turn 13 も含まれる。v18 の 2 ガードが 0 回だったのとは
異なり、確実に拘束する。

対象規模: 免疫 Active への死に swing は全 1,903 Shadow Bullet 中 **168 回 (8.8%)**、
42 戦に集中し (成績 22-20)、うち 35 戦が Kangaskhan/Crustle。

## 2. Boss を安全ゲートにしない根拠

別分析は Boss 使用率 (v20 0.30/試合 対 rank3 0.65) を P0 に挙げた。プロジェクト
自身の probe (`analyze_grimmsnarl_v16_boss_routes.py`、v15 時点で「446 発中 1 回」と
結論したもの) を v19 二提出 + v20 の 130 戦に流した結果:

| | 値 |
| --- | ---: |
| Shadow Bullet | 457 |
| サイド 0 の swing | 163 (35.7%) |
| **手札の Boss が今ターンのサイドを増やしたはずの回数** | **8 / 457** |
| 取り逃したサイド合計 | 8 (= 0.06 サイド/試合) |
| Boss gain 分布 | +1 が 8、0 が 24、**負が 11** |

100% 使っても 0.06 サイド/試合で、負利得が 11 回ある。同ターン利得としては
レバーにならない。一方フィールド 21 パイロットの勾配では `boss_taken` は
rho +0.216 / p=0.35 で有意でなく、有意なのは `petrel_boss` (rho +0.581, BH 有意)。
したがって Boss は**学習重みと退行チェック項目**として扱い、ルール化しない。

## 3. retreat lock: 6 特徴を追加、ただし行動は動かなかった

保存 529 戦で、自ターン何手目に Grimmsnarl ex が場に出るかが勝率のほぼ全て
(自ターン 2 で 0.689、5 で 0.364、出なければ 0.000)。場に出たターンと攻撃可能に
なったターンは **511/511 戦で一致**する (Punk Up が進化時に給エネするため)。
遅延の主機構は、ready な Grimmsnarl がベンチにいて Active がエネ 0 の
Snorunt/Munkidori/Froslass で逃げられない状態 — 529 戦中 82 戦・128 自ターン。

追加した 6 列 (`active_retreat_locked`, `bench_marnie_body_count`,
`bench_locked_ready_attacker`, `retreat_lock_risk`,
`candidate_funds_active_retreat`, `candidate_leaves_retreat_locked`) は既存
プリミティブから決定的に再構成でき、133 戦・12,108 判断・66,158 候補行で
**学習/実行の不一致 0**。

しかし行動パネルでは動かなかった:

| | v20 | v21 |
| --- | ---: | ---: |
| funds_active_retreat (122 提示自ターン) | 0.459 | 0.443 |
| leaves_retreat_locked | 58 | 58 |

**この施策は行動面では無効と記録する。** 単発判断の修正が 1,881 手貼り中 4 回しか
拘束できないことは事前に測っており、学習側に回したが、それでも届かなかった。
次版で扱うなら、盤面到達そのもの (どの basic を Active にして何を最初に立てるか)
の側に移す必要がある。

## 4. 学習: 10 アーム、最大の利得は patience の是正

v20 を厳密に再現してから比較した (patience 200 / 842 特徴 / v20 mask →
513 木、test 0.8047、MAIN 0.7426 で metadata と一致)。

| arm | 特徴 | mask | patience | 木 | val | test | MAIN |
| --- | ---: | --- | ---: | ---: | ---: | ---: | ---: |
| v20 再現 | 842 | v20 | 200 | 513 | 0.8019 | 0.8047 | 0.7426 |
| v20 + patience | 842 | v20 | 800 | 1120 | 0.8037 | 0.8073 | 0.7434 |
| mask のみ | 842 | v21 | 200 | 385 | 0.8044 | 0.8010 | 0.7367 |
| mask のみ | 842 | v21 | 800 | 1620 | 0.8067 | 0.8060 | 0.7412 |
| 特徴のみ | 848 | v20 | 800 | 3650 | 0.8051 | 0.8074 | 0.7436 |
| 特徴のみ | 848 | v20 | 1600 | 3650 | 0.8051 | 0.8074 | 0.7436 |
| 両方 w2.0 | 848 | v21 | 200 | 261 | 0.8030 | 0.8011 | 0.7346 |
| 両方 w2.0 | 848 | v21 | 800 | 1706 | 0.8063 | 0.8063 | 0.7428 |
| 両方 w1.5 | 848 | v21 | 800 | 1457 | 0.8042 | 0.8065 | 0.7446 |
| **採用 両方 w2.5** | **848** | **v21** | **800** | **1380** | **0.8061** | **0.8092** | **0.7444** |

読み方:

- **patience 200 は全アームで早すぎる**。同一設定で 513→1120 木、test +0.26、
  MAIN +0.08。v20 は必要な木の半分以下で出荷していた。patience 1600 は 800 と
  同結果なので 800 で収束している。
- **6 特徴単独の効果はほぼゼロ** (0.8074/0.7436 対 0.8073/0.7434)。
- **mask 単独はやや有害** (0.8060/0.7412 対 0.8073/0.7434)。
- 両方 + w2.5 が test 最良 (0.8092)、MAIN も 0.7444。ただし val では 842+v21mask
  (0.8067) が上で、p800 アーム間の差は 0.06-0.3 ポイントに収まる。**この差は
  ラダーの解像度を下回る**ので、指標での優劣は主張しない。採用理由は「診断した
  機構を含み、test/MAIN を退行させない唯一のアーム」である。

## 5. 行動パネル (133 戦・11,658 判断、安全層込みの実応答)

| 指標 | elite band | v20 | v21 |

| attack (自ターンあたり) | 0.9407 | 0.9205 | 0.9094 |
| boss | 0.3847 | 0.2017 | **0.2275** |
| petrel_boss | 0.0931 | 0.0947 | **0.1006** |
| dead_shadow | - | 0.5897 | 0.5897 |
| funds_active_retreat | - | 0.459 | 0.443 |

Boss は +2.6 ポイント、Petrel→Boss は elite band を上回る 0.1006 まで戻った。
`dead_shadow` が変わらないのは設計どおりで、`_preserve_closer` は breaker を残す
ために無害な Shadow を選ぶ。

## 6. v18 でないことの確認

v20 と v21 を同じ保存盤面で teacher-forcing した直接比較:

- 133 戦・11,658 判断のうち **774 判断 (6.64%) が異なる**
- **130/133 戦に到達**、MAIN だけで 542 判断

v18 は実質同一方策だったが、v21 はそうではない。
