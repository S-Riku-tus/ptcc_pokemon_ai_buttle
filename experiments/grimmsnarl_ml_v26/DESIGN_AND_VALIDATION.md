# Grimmsnarl ML v26 — 設計判断と検証

## 結論

v26はv25を全面的に再学習した版ではない。v25の実ログが示したのは、模倣学習そのものの崩壊ではなく、レース系で改善する一方、壁・耐久系で軌道が崩れる局所回帰だった。そのため、v22を常時のチャンピオン方策として維持し、v25は同型対面における探索候補の生成にだけ使う。

新規性は、保存された教師の一手を直接採用するだけだった構成から、実ゲームエンジンで「現在の自ターン → 相手の応手 → 次の自ターン」まで進め、学習済み局面価値で比較するモデルベース計画へ移した点にある。ただし探索の不確実性を全面に露出させず、公開情報で同型と強く確認できる中盤以降、3つの非公開札仮説が全て同じ結論になる場合だけv22を変更する。

## 1. v25から何を残し、何を捨てるか

v25の52戦分析では、レース系は0.735（34戦）でv22の0.653を上回った一方、壁・耐久系は0.167（18戦）、Crustle/Ogerpon/Cornerstone系は0.125（8戦）だった。したがって、52戦全体の0.538だけを見て学習方式全体を否定するのも、v25をそのまま既定方策にするのも不適切である。

採用したもの:

- AlphaTCGに寄せたv25ランカーが作る、v22とは異なる合法手候補
- 1手の教師模倣だけでなく、数手先の交換結果を評価しようとする方向性
- hard stateを通常局面と分けて扱う考え方

採用しなかったもの:

- v25を全局面の既定方策にすること
- 壁局面のないvalidationで決まったbest iteration 228を強さの根拠にすること
- 行動後相関から単一ルールを読み、そのまま全面介入すること
- 正体不明の相手デッキに対して、こちらと同じ60枚だと仮定した探索を行うこと

## 2. v26の意思決定階層

最終手は次の順序で作られる。

1. v22の1220-rated pilot条件ランカーが基準手を出す。
2. 既存の1-ply算術プランナーが、即時の確定的な優越だけを反映する。
3. 公開されたGrimmsnarl系統に加え、Froslass/SnoruntまたはMunkidoriまで確認できた場合だけH2探索を検討する。
4. v25ランカーの手とv22上位手を最大3候補にする。
5. 実Search APIで各候補を、相手応手と次の自ターンが完了するまで進める。
6. 局面価値と賞品交換の安全条件を満たした場合だけ探索手へ変更する。
7. 壁が公開されている場合は、非ex攻撃ルートを作る決定論的ガードを適用する。
8. 壁がActiveなら、実績のあるv21 WallBreakGuardを最後に適用する。

どの段階が手を変えたかは`last_trace`に残る。探索エラー、モデル欠損、時間不足、仮説間不一致、枝の未完走は全てv22へ戻る。

## 3. 本当の2手先探索

v25は将来の結果を直接シミュレーションして提出時に読むエージェントではなく、上位教師の複数ターン判断を一手分類へ間接的に蒸留したモデルだった。v26は初めて、提出時にゲームエンジンの状態遷移を実行する。

探索範囲は以下である。

```text
現在の候補手
  └─ 現在の自ターンの残り
      └─ 相手の1ターン全体
          └─ 次の自ターン全体
              └─ 相手の昇格・賞品処理まで解決した次MAIN局面を評価
```

非公開領域は3通りに決定化する。自分側は公開済み・手札・既知賞品を60枚から差し引き、相手側は同型の公開シグネチャが揃った場合だけ同じ60枚を事前分布に使う。3標本全てで同じ候補が勝ち、各標本でv22以上、平均勝率差が0.04以上、2ターン後の賞品交換が悪化せず、新しいデッキ切れも作らない場合だけ採用する。

1試合の探索上限は180秒、600秒のoverage bankから200秒を必ず残す。1ターンに1回までで、実測平均コストに対して残予算が不足すれば停止する。

## 4. 局面価値モデル

`corpus_v25_with_alphatcg.npz`の4,054試合、332,139局面、22チームを使い、手の分類ではなく、その公開局面から最終的に勝つ確率を学習した。チーム単位・試合単位で分割しており、同一試合の局面がtrainとtestへ漏れない。

| 指標 | validation | test |
|---|---:|---:|
| 局面数 | 40,626 | 37,441 |
| ROC AUC | 0.8434 | 0.8569 |
| Log loss | 0.4801 | 0.4669 |
| Accuracy | 0.7488 | 0.7515 |
| 試合平均AUC | 0.9100 | 0.9397 |

ターン別test AUCは1–4が0.7196、5–8が0.8648、9以降が0.9275だった。この差をモデル選択後の説明で終わらせず、v26は探索開始をターン5に固定した。

上位特徴は賞品差、相手Active ID、Freezing Shroudの純交換、準備済みMunkidori数、相手総HP、両者のデッキ枚数だった。今回必要な「攻撃開始の速さ」ではなく「その後の交換と時計」を直接表現している。

## 5. 壁対面の軌道修復

壁をActiveにされてから0ダメージ攻撃を禁止するだけでは遅い。v25では壁対面1ターンあたりFroslassが0.30体、ready Morgremが0.009体まで落ち、Morgremは1.377体あるのにエネルギーが分散していた。そこで二層に分けた。

予防層 `WallTrajectoryGuard`:

- Punk Upの余剰エネルギーを、1体のMorgremが2エネルギーになるよう集中する。
- 主力Grimmsnarl exの2枚目と、Munkidoriの最初の1枚を絶対に奪わない。
- 準備済みGrimmsnarl exが既にいるとき、最後のMorgrem/Impidimpを進化で消さない。
- Froslass系もready Morgremも無い状態で、3体目Munkidoriが5枠目を埋めるのを防ぐ。

反応層 `WallBreakGuard`:

- v21で検証済みのコードを変更せず移植した。
- dead Shadow BulletよりMorgrem/Impidimpの攻撃、給電、退却、昇格を優先する。
- 最速の非ex・特性なし攻撃ルートを進化で失わない。
- Bossで即時賞品が取れる場合や、Bench 30で賞品が取れる攻撃には介入しない。

デッキ時計は、Lillie's Determinationが残り手札を戻した後に6枚（賞品6枚なら8枚）引く正確な純減少を計算し、その任意行動だけでデッキが空になる場合に限定して拒否する。長期戦全体を雑に止める規則にはしていない。

## 6. 実ログ反実仮想検証

v25の2提出、利用可能な87試合から、壁を公開した11試合を全件、非壁対照を事前固定で12試合選び、保存教師行動で内部履歴を進めた。H2を無効にし、v22＋1-ply時点と決定論的ガード後を同じ実到達盤面上で比較した。

| セル | 評価判断 | v22からの変更 |
|---|---:|---:|
| 壁が公開・非Active | 376 | 4 |
| 壁がActive | 797 | 34 |
| 通常対面 | 77 | 0 |
| ミラー対面（H2無効） | 19 | 0 |

合計1,269判断で変更は38件、全て壁セルだった。Munkidoriの最初のエネルギーを守った判断は63件、Punk Up集中は3件、最後のBench枠保持は6件、壁Activeでの給電は27件、dead Shadow Bullet置換は6件だった。ガード例外は0件。

この検証は「勝率が上がった」ことの証明ではない。保存ログの将来は実際に選ばれたv25行動で続くため、別行動後の勝敗は観測できない。一方で、介入対象が意図した欠陥セルに限定され、通常セルを変えていないことは直接確認できる。

## 7. 実エンジン探索スモーク

episode 93123216の公開ミラー、ターン6で実施した。v22は候補23、v25は候補22を提示した。最大3候補×3決定化の9枝を全てH2終端まで12.808秒で完走した。この局面では候補変更が全標本でv22を支配しなかったため、`skip_not_dominant`で23を維持した。

重要なのは、変更が発生しなかったことも成功条件だという点である。探索を実装しただけで毎回その答えを採用するのではなく、根拠不足ならチャンピオンを保持する仕組みが実エンジン上で作動した。

## 8. 昇格判定

オフラインで確認できる条件は満たしたが、v26がラダー上でv22より強いことはまだ未観測である。次の提出は同一時間窓でv22対照とv26候補を並べ、全体レートだけでなく次を先に登録して判定する。

1. 壁セルがv22水準以上へ戻ること。
2. 非壁レース系がv25の改善を失わない、少なくともv22へ非劣性であること。
3. 950+ミラーの勝率とH2の探索回数、採用率、平均価値差。
4. H2の時間消費、budget stop、branch errorが安全範囲であること。
5. デッキ切れ負けが再発しないこと。

壁セルをv22の0.545まで戻すだけなら、元分析のv25露出比では約+3.4勝、約+45 Eloの余地がある。ただしこれは反実仮想の期待値であり保証ではない。1000超えの追加余地は、主に950+ミラーでH2が安全に数勝を上積みできるかに依存する。
